# Q1-006 — 공통 tanh 템플릿의 구조 탐색 비교

[실행 전 계획](../../../docs/protocols/Q1-006_v02_고정구조와구조탐색_실험계획.md)과 [수치 명세](../../../docs/protocols/q1_006_v02_plan.json)를 따른다. F0/F1은 같은 초기 집단에서 가중치만/구조도 변경하는 조건이며 기존 R0/S0 환경을 유지한다. 완료한 Q1-005에서 탐색·잠금·감사 코드를 새 패키지로 복사해 조건을 분리했다. 과거 소스는 수정하지 않는다.

소스·계획·전체 게이트를 잠근 뒤 훈련 전용 예비→본 비교→사전 기준 통과 시에만 확인을 실행한다. 출력은 `../results_q1006_v02/`다. 실제 명령·예산·해석 한계는 계획서가 기준이다. 완료 출력과 게이트를 다른 버전으로 덮어쓰지 않는다.
