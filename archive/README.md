# 보존 자료 안내

이 폴더는 당시 자료의 내용을 바꾸지 않고 보존한다. 현재 연구의 공식 보고서는 [보고서 목록](../docs/reports/README.md)에 있다.

| 위치 | 내용 | 주의 |
|---|---|---|
| original_simulator | 처음 작업 폴더에 있던 시뮬레이터·실행 진입점·테스트 | 당시 코드. 현재 Q1 실행본과 구분 |
| reviews/phase1_review_20261015 | 전달 패치를 검토한 복사본·검토 문서·로그 | 사용자 전달 코드의 검토 이력이며 새 본 실험 결과가 아님 |
| documents | 이전의 긴 연구 목표·진행 계획 통합 원문 | 당시 예정·현재 상태 표현과 경로를 그대로 보존 |
| reference_materials/pdf_read.txt | 경제 게임 제작 대화의 PDF 추출 텍스트 | 이번 기억·상호작용 실험의 결과 자료와 구분 |
| generated_cache | 정리 전 루트 Python 캐시 | 원본을 임의 삭제하지 않고 보존 |

기존 자료에 실행자·모델 ID가 기록되어 있지 않으면 소급해서 추정해 넣지 않는다. 새 공식 보고서는 실제 확인 가능한 수행 주체와 독립 검토 상태를 마지막 절에 명시한다. 보존 자료와 자동 생성 집계 Markdown은 현재 공식 실험 보고서를 대신하지 않는다.

옛 경로의 새 위치는 [대응표](../docs/04_폴더구조와재현.md), 원본 내용 보존은 [SHA-256 검사](../docs/management/preservation_check.json)로 확인한다.
