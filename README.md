# 개체의 기억과 환경 적응 연구

공동 수정은 [참여 규칙](CONTRIBUTING.md)에 따라 Issue와 PR로 진행한다. 설치: `python -m pip install -r requirements.txt`. 검사: `python -B -X utf8 tools/check_research_layout.py --tests`. 실행별 원자료는 [Release 다운로드·복원 안내](evidence/README.md)를 따른다.

처음 읽는 사람은 아래 순서로 보면 된다. 연구 내용은 한국어 문서로, 실행 코드와 원자료는 연구별 작업 폴더로 관리한다.

1. [연구 목적](docs/01_연구목적.md): 무엇을 알아보려는 연구인가?
2. [연구 계획](docs/02_연구계획.md): 큰 목표에서 어떤 질문을 순서대로 확인하는가?
3. [현재 현황](docs/03_연구현황.md): 어디까지 실행했고 무엇을 확인했는가?
4. [실험 보고서 목록](docs/reports/README.md): 각 실험의 방법·결과·한계·수행자는 누구인가?
5. [보고서 작성 규칙](docs/rules/보고서_작성규칙.md)과 [보고서 양식](docs/templates/실험보고서_양식.md): 새 보고서를 어떻게 작성하는가?

## 폴더 안내

| 폴더 | 역할 |
|---|---|
| [docs](docs/README.md) | 연구 목적·계획·현황·규칙·양식·프로토콜·공식 보고서·연구일지 |
| [studies/working_memory](studies/working_memory/README.md) | 작업 기억 연구의 코드·테스트·명세·정책·원자료·로그 |
| [studies/interaction](studies/interaction/README.md) | 이동·수집 연구의 코드·테스트·명세·정책·원자료·로그 |
| [archive](archive/README.md) | 초기 시뮬레이터·패치 검토본·이전 통합 문서·참고자료 |
| tools | 폴더 이동·문서 정리·링크와 보고서 규칙 점검 도구 |

현재 [Q1-006 고정 구조·구조 탐색 비교](docs/reports/Q1-006_고정구조와구조탐색_비교.md)의 본40짝 시드·120작업·감사를 완료했다. 평균 완료율은 F0 12.40%·F1 22.12%·공통 무작위 탐색2.16%였고, F0 우세 진행 기준을 충족하지 않아 확인을 추가하지 않았다.80% 이상 발견은3/40·5/40·0/40으로 안정성은 미해결이다. 단일 테스트100% 정책은 진화로 발견됐다. 생애 학습·일반 지능의 증거로 확대하지 않는다. 후속 [Q1-007](docs/reports/Q1-007_탐색예산_비교.md)은 구현·훈련 전용 예비·감사를 완료했으나 비용 기준 미통과로 본을 보류했다. 성능 효과는 미측정이며 새 버전의 저장·평가 효율화 설계가 다음이다.

모든 공식 실험 보고서의 **마지막 절에는 실험 수행자·보고서 작성자·모델 기록·독립 검토 상태를 반드시 명시**한다. 확인되지 않은 이름이나 모델 버전은 추정하지 않는다.

재현과 옛 경로의 새 위치는 [폴더 구조와 재현 안내](docs/04_폴더구조와재현.md), 정리 내역은 [폴더 정리 이력](docs/management/폴더정리_이력.md)을 참고한다.
