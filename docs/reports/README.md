# 실험 보고서 목록

각 보고서는 독립적으로 읽을 수 있게 방법·지표·근거·한계와 마지막 수행 기록을 포함한다. WM-001~004와 Q1-000~003은 기존 실행 기록의 분리·작성본이고, Q1-004~005는 새 실행을 보고한다. Q1-008은 결과를 본 뒤의 사후 진단·문서 검토다(Q1-006·007은 미실행 예정 식별자). 독립 검토는 미완료다.

WM과 Q1은 환경·지표·학습 설정이 다르다. 보고서가 여러 개라고 독립적인 확인 실험 수가 그만큼 늘어나는 것은 아니다. 특히 Q1-002~003은 Q1-001의 같은 후보와 이미 평가한 목록을 사용했다.

새 보고서는 [양식](../templates/실험보고서_양식.md)을 복사하고 [규칙](../rules/보고서_작성규칙.md)에 따라 이 목록에 추가한다. `RESULTS.md` 등 실행 폴더의 자동 집계는 원자료에 연결된 분석 산출물이며 위 공식 보고서와 구분한다.
