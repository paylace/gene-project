**두 개입은 초기 반복 고착을 줄였지만, 초기 개체가 과제를 안정적으로 해결하게 만들지는 못했다.** 좌표 중심화는 정답 방향 전환 반응을 늘렸고 출력 자기순환 제거는 출력 누적을 크게 줄였다. 이는 같은 초기 유전체에 가한 직접 조작의 결과다. 학습·진화·후보 선발은 하지 않았으며 진화 개선의 확인 결과가 아니다.

## 1. 방법과 고정 조건

초기 원형은 시드 6000~6499의 500개다. 각 원형은 기존 A0 초기화로 한 번만 생성하고 네 조건에 복제했다. 초기 4모듈·연산·가중치·모듈 기억·다른 순환은 유지했다. 좌표 중심화는 위치와 목표만 2x−1로 바꿨으며 남은 목표·행동 비율은 그대로다. 자기순환 제거는 출력 노드의 자기 간선만 지웠다. 원형과 변환 유전체를 함께 저장했다.

| 조건 | 좌표 입력 | 출력 자기순환 |
|---|---|---|
| C0N0 | 0~1 | 원래대로 |
| C1N0 | −1~1 | 원래대로 |
| C0N1 | 0~1 | 제거 |
| C1N1 | −1~1 | 제거 |

환경은 기존 7칸·순차 목표 3개·24행동이며 왼쪽·오른쪽·수집을 선택한다. 보상은 수집+1·매 행동−0.01이고 종료는 세 목표 완수 또는 예산 소진이다. 실패 수집 종료나 추가 벌점은 넣지 않았다. 같은 원형의 조건 간 난수 파생에서 조건 이름을 제외했다. 전체 1,512조합을 조건마다 한 번 평가했다. 이는 이미 관측한 benchmark의 재사용이며 새 환경 일반화 검증이 아니다.

## 2. 측정·분석

주 진단 지표는 전체 에피소드 중 마지막 6행동이 같은 행동이며 모두 벽 충돌 또는 모두 실패 수집인 비율이다. 단순 이동의 반복과 구분한다. 실패만을 분모로 제한하지 않으며 엄밀한 흡수 상태라고 해석하지 않는다. 보조 지표는 완료율·원래 보상·수집·회복·출력 크기와 다음 초기 반응성이다.

초기 내부 상태를 0으로 두고 위치7×목표7×남은 목표 수3×행동 수{1,12,24}=441상태를 평가했다. 이는 방문 분포가 아닌 균등 가상 상태 검사다. 실제 정책과 같은 softmax 최대 확률의 동률 집합을 계산하고, 정답이 그 집합에 있으면 1/집합크기를 정답 선택 확률로 기록했다. 동률 난수를 다른 관측에서 소비해 입력 반응으로 세지 않았다.

정답 행동이 반대인 좌우 목표315쌍에서 양쪽 모두 유일 정답인 비율을 측정했다. 수집63상태는 따로 집계했다. 따라서 입력 무관 무작위나 한 방향 정책은 좌우 쌍을 통과할 수 없다. 이전의 ‘같은 방향을 요구하는 인접 목표에서 행동이 바뀌는가’와 다른 검사다.

짝 비교 단위는 유전체 500개다. C1N0·C0N1·C1N1 각각의 C0N0 대비와 상호작용을 사전에 정했다. 평균·중앙값·표준편차·양수/음수/동률과 시드 원값을 기록했다. bootstrap은 시드 짝을 보존한 10,000회, 난수72009의 개별95% 백분위 구간이다. 기술적 구간이며 동시 구간·유의성 검정·설계 채택 기준으로 사용하지 않는다. 확인 실행·표본 추가는 없다.

### 3.2 반응과 출력 누적

좌표 중심화의 좌우 쌍 정답률 차이는 +2.9244pp(개별 기술 구간 +2.0051~+3.8807pp)였다. 수집 정답률 차이는 −0.2921pp(−2.0286~+1.4350pp)로, 방향 반응 변화와 같은 양으로 합치지 않는다. 출력 자기순환 제거의 초기 첫 스텝 효과는 모든 500원형에서 정확히0이었다. 이전 상태가0이라는 구조적 대조와 일치했다.

## 4. 실행·감사·오류 기록

신규25+기존148=173개 검사와 훈련 목록 예비를 통과했다. 본 프로그램의 평가·감사·집계 시간은 약 136.24초였다. 구현·검사·예비·보관·업로드 시간은 별도다.

| 범위 | 실제 에피소드 호출 | 단일 초기 상태 계산 | 감사의 단일 상태 재계산 |
|---|---:|---:|---:|
| 초기500원형 본 평가 | 3,024,000 | 882,000 | 882,000 |
| 고정 대조5개 | 30,240 | 8,820 | 8,820 |
| 훈련 목록 예비 | 192 | 3,528 | 3,528 |
| 추가 훈련 비용 표본 | 12,096 | 3,528 | 3,528 |

본·고정 대조 전체3,054,240기록의 환경·보상·종료·고착 분류를 행동으로 재생했다. 첫 스텝 출력과 동률 집합은 전부 다시 계산했다. 에피소드 전체의 신경망 행동과 출력 최대값을 모두 별도로 재계산한 것은 아니다. 실제 act와 batch의 정합성은 기술 fixture에서 확인했다. 유전체 불변·변환·캐시·파일 지문을 함께 점검했다.

UUID 작업 원장에서 본·대조의 미확정 중단0, 추가 호출0을 확인했다. 예비의 완료 자료 재개는 추가 에피소드0이었다. 실제 호출과 계획 슬롯이 일치하며 에피소드 호출에 초기 상태 계산이나 행동 재생을 합치지 않았다.

첫 실행 게이트는 모든 검사가 통과했으나 JSON을 출력하는 wrapper의52+35개 검사를 개수 합산에서 놓쳐86개로 표기했다. 본·예비 전에 집계 도구를 고쳐 최종173개 게이트를 별도로 저장했고 이전 기록도 보존했다. 핵심 평가 소스·수치 조건은 바뀌지 않았다. [개발 기록](../management/q1_009_gate_development.json)에 범위를 남겼다. 실행 소스 고정 후 오류·제외 시드는 기록되지 않았다. 이는 모든 버그가 없다는 증명이 아니다.

## 5. 해석과 다음 질문

같은 원형에서 요인만 바꿨을 때 초기 고착과 출력 누적에 직접적인 차이가 생겼다. 따라서 입력·순환 설정이 초기 행동 편향에 영향을 준다는 근거는 얻었다. 두 변경 결합에서도 고착률82.60%가 남고 완료율은0.015741%였다. 반응 개선과 과제 해결을 같은 성공으로 취급할 수 없다.

좌표2x−1은 원점 이동과2배 척도 변경을 함께 포함한다. 이 둘의 개별 효과는 이번 C요인 안에서 분리하지 않았다.

이 진단에는 학습·번식이 없으므로 ‘변경하면 진화도 좋아진다’는 결론을 내릴 수 없다. 기존 진화 후보의 실패 원인 전체를 초기 분포만으로 설명할 수도 없다. 수작업 정책의 성공은 표현 가능성의 대조이며 자력 획득 성과가 아니다. 큰 모델이 필요하다거나 입력 중심화 하나로 해결된다고 판단하지 않는다.

다음은 Q1-006의 공통 순방향 템플릿에서 가중치만 탐색하는 조건과 구조 변경을 허용하는 조건의 비교다. 초기 고착 진단을 근거로 여러 요인을 동시에 바꾸지 않고, 두 조건이 공유할 표현·해결 가능한 수작업 기준·유효/무효 변이·비용·판정 기준을 먼저 고정한다. 이번에 가장 낮은 고착 조건을 새로운 표준으로 자동 채택하지 않는다.
