# Q1-004 실행 준비 검증과 훈련 전용 예비 기록

버전1.0 / 2026-10-16 한국 시간 / W3~W8 구현·검사·예비 완료. 본 비교의 성능 결과 보고서와 구분한다.

## 목적·구현 범위

[기존 계획](../protocols/Q1-004_v02_실험계획.md)의 조건·시드·예산·판정을 유지하며, [W1/W2](Q1-004_W1-W2_구현검증.md)에 이어 동결 평가기, 관찰기, 조건별 탐색, 후보 잠금, 원자 저장·중단/재개, 분석·감사, 단계별 실행기를 구현했다. 완료된 v0.1의 소스·결과는 수정하지 않았다.

환경·분할·기준 정책·rollout은 기존 파일을 새 패키지로 복제해 보존했다. 주 계산은 기존 batch 순서를 유지하며 scalar 대조를 둔다. 평가 API는 단계와 분할을 확인하고, 본 테스트는 모든 실행의 후보와 blind 선발을 잠근 뒤에만 허용한다.

## 실제 검사 결과

[실행 게이트](q1_004_execution_gate.json)에 명령·소스 SHA-256·Python/NumPy·통과 여부를 기록했다.

| 검사 | 결과 |
|---|---|
| 신규 패키지 검사 | 52개 통과. 기존25개에 평가·관찰·재개·잠금·감사·통계 검사를 추가 |
| 기존 WM/Q1 검사 | 35개 통과 |
| 계획 도구 검사 | 12개 통과 |
| 전체 자동 검사 | 99개 통과 |
| 동결 기존 소스 | 30개 해시 일치 |

확인한 주요 사례는 다음과 같다.

- A0 batch의 기록·지표와 기존 실행기의 일치, 세 조건의 scalar/batch 일치, 에피소드 순서·반복에 따른 상태 독립성.
- 관찰기 켬/끔의 행동·보상·유전체 불변. 반사 검사는 이전 상태와 RNG를 복제하며 실제 경로에 쓰지 않음. 단순 행동 전환과 양방향 정답을 구분함.
- 전체1,512조합에서 좌표 규칙의 최단 해결, 기존35쌍 프로브 정의 유지.
- 세 조건·두 방법의 연속5회차와2회차 중단+3회차 재개 결과 일치. 완료 회차 바이트, 후보·계보·난수·모듈 ID를 대조함.
- 회차 저장 직후 실패를 주입하여 같은 회차를 재계산해도 기존 파일을 덮어쓰지 않음. 재계산한 실제 작업은 별도 attempt 기록으로 계수함.
- 체크포인트·소스·분할·조건·완료 기록 변경을 거부함. 평가 중 끊긴 작업의 정확한 호출 수를 알 수 없으면 상한과 미확정 상태를 기록함.
- 후보가 누락되거나 blind 검증 기록이 바뀌면 테스트를 거부함. 잠금 경계 unit fixture에서는 실제 held-out 계산을 mock하여 성능을 열지 않음.
- 저장 개체·점수·훈련 묶음·후보 선발·유전 연산·최종 RNG/ID를 감사 코드로 재구성함.
- 0/8/9개 양수, Holm 첫 단계 실패·동률, 평균 차이 미달, A1 우선 선택, 확인 단일 대비, 분모0(null)을 합성 자료로 검사함.

자동 검사는 검사 사례의 동작을 확인한 것이며 모든 버그의 부재나 독립 과학 검토를 뜻하지 않는다. 통계 fixture는 실험 성과가 아니다.

## 훈련 전용 예비

시드901/902 × A0/A1/A2 × evolution/random =12실행을 수행했다. 집단20·5회차·회차당훈련24개다. 각 실행을2회차에서 실제 중단한 뒤3회차를 재개했다.

- 계획 훈련 슬롯: **28,800**.
- 완료 attempt 기준 실제 에피소드 호출: **28,800**. 중복 계산·미확정 중단 작업 없음.
- 완료한 모든 개체·선발·유전 연산 감사 통과.
- 검증·테스트 평가: **0**. 예비 성적에 따른 조건·예산·임계값 변경 없음.
- 탐색·중단/재개 벽시계: 약4.26초, 검사·보고·프로세스 시작 등의 부가 시간은 별도.
- 당시 출력 크기: 약2.78MB. 전체 비용의 보증이 아님.

원 기록은 `studies/interaction/results_v02/pilot/cost_report.json`과 단계별 protocol/datasets, 실행별 checkpoint/round/attempt/result다. 원자료는 로컬 보존하고 소규모 프로토콜·집계만 Git 추적 대상으로 분리했다.

관찰기 비용 표본72개와 별도 batch 비용 표본2,340개를 **추가 훈련 자료 검사**로 수행했다. 이2,412개는 본 탐색·예비28,800슬롯에 합쳐 숨기지 않고 별도 계수했다. 성능 지표는 조건 선발에 쓰지 않았다.

## 실행 명령·현재 위치

저장소 루트에서 구현 게이트를 실행했다.

```powershell
python -B -X utf8 tools/check_q1_execution.py --output docs/management/q1_004_execution_gate.json
```

`studies/interaction/`에서 다음 명령을 실행했다.

```powershell
python -B -u -X utf8 -m evosim_interaction_v02.run pilot --gate ../../docs/management/q1_004_execution_gate.json --workers 2
python -B -u -X utf8 -m evosim_interaction_v02.run main --gate ../../docs/management/q1_004_execution_gate.json --pilot-report results_v02/pilot/cost_report.json --workers 2
```

본 비교60실행을 시작했다. 모든 탐색과 사전 감사가 끝나면 후보/검증에서만 선발한 blind를 잠그고, 세 역할 테스트·프로브·관찰 진단·원자료 재생 감사를 수행한다. 최종 완료 시 별도 Q1-004 결과 보고서를 작성한다. 진행 중 수치를 최종 결과나 개선으로 보고하지 않는다.
