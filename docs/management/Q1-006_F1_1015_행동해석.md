## 구조·획득 과정

네 모듈 무작위 집단20개체에서 출발해100회차 진화한 F1 실행의 검증 선발 후보다. 최종 후보는8모듈·tanh·순방향 연결이며 순환과 생애 학습은 없다. 현재 위치·현재 목표·남은 목표 비율·남은 행동 비율을 받아 왼쪽/오른쪽/수집 점수를 계산한다. 에피소드 안에서 가중치를 배우지 않으며 정답 가중치를 수작업으로 넣지 않았다.

이 실행에서 당시까지의 검증 best 완료율은1회차0%,10회차40.48%,20회차73.81%,40회차92.86%,60회차100%였다. 마지막100회차 후보가 최종 선발됐다. 이것은 시드1015 하나의 과정이며 조건 전체의 평균 곡선은 아니다.

## 100%의 범위와 효율

테스트84개 목표 목록×6개 시작 위치=504개 에피소드를3회씩 평가한1,512기록에서 모두24행동 안에 세 목표를 수집했다. 검증252에피소드×3회도100%였다. 동률 선택0이므로 반복3회는 같은 정책의 결정적 행동을 반복한 것이며1,512개의 서로 다른 새 상황으로 세지 않는다. 새 환경·다른 시간제한의 성공률은 이번에 시험하지 않았다.

테스트 평균 행동 수21.87, 해당 상황의 최단 행동 평균11.77로 평균10.10행동을 더 썼다. 평균 벽 충돌2.82회·실패 수집1.29회였다. 성공률은 높지만 경로는 비효율적이다.

예를 들어 위치0에서 목표2→6→4를 수집하는 저장 기록은18행동에 끝났고 최단은11행동이다. 처음 왼쪽 벽으로4번 움직인 뒤0→1→0→1→2로 이동해 수집했다. 이후6·4를 수집하는 사이에도 한 번 실패 수집이 있었다. 이를 실수를 인식하고 배우는 과정이라고 해석하지 않는다.

## 현재 목표와 남은 시간에 따른 반응

같은 위치1·남은 목표3개·남은 행동24에서 목표0이면 왼쪽, 목표5이면 오른쪽이었다. 실제 방문 기록에서 다른 입력이 같은 목표 대비 중79묶음에서 행동이 달랐다. 목표와 무관한 고정 행동 순서로만 설명되지는 않는다.

반대로 위치0·현재 목표0·남은 목표3개가 같아도 남은 행동23~18에서는 왼쪽,17에서는 수집을 선택했다. 이처럼 시간만 다른 방문 상태56묶음에서 행동이 달랐다. 초기 벽 대기와 남은 시간에 따른 행동 전환이 관찰된다. 따라서 즉시 좌표 비교를 실행하는 정책이라기보다 시간·진행 정도·목표·위치에 조건화된 고정 정책이라는 해석이 맞다. 방문하지 않은 모든 상태에서의 역할이나 각 모듈의 인과 기능까지 입증한 분석은 아니다.

첫 좌표 규칙 행동과 달랐던 경우는 서로 다른187/504에피소드, 반복 포함561/1,512회였고 모두 완료했다. 여기서 ‘회복’은 행동 기록의 끝에서 성공했다는 뜻이다. 내부 기억·오류 인식·생애 학습을 증명하지 않는다.

F1 전체의 평균 완료율은22.12%,80% 이상 후보 발견은5/40이며100% 사례는 하나였다. 이 후보는 능력의 존재 사례이며 반복 탐색의 안정성이나 일반 지능을 보장하지 않는다.
