작성2026-10-17 한국 시간. 분류: 구현·훈련 전용 예비 검증. 본 성능 결과는 이 문서에 포함하지 않는다. [계획](../protocols/Q1-006_v02_고정구조와구조탐색_실험계획.md)과 [수치 명세](../protocols/q1_006_v02_plan.json)가 기준이다.

## 검사와 기술 실패

v0.1 신규19+기존173=192검사는 통과했으나 예비 단계의 공식 작업 수를 직접 검사하지 못했다. 예비가6작업만 생성했고 all_jobs_complete=false였으므로 본 진행 자격을 얻지 못했다. 본 실험 미실행·시드 제외 없음. 기존35소스·계획·게이트·14,400예비 호출과3,120비용 표본을 그대로 보존했다. CLI가 미완료 판정을 저장해도 정상 종료한 문제도 기록했다. [원본 실패 기록](q1_006_v01_pilot_failure.json).

새 패키지와 출력v0.2에서 예비에만 양쪽 무작위 대조를 포함하고 미완료 예비 종료 코드를 보강했다. 공식 예비8작업·본 공통 대조120작업 검사를 추가했다. 가중치·구조 연산·초기 분포·표본 수·판정은 변경하지 않았다.

[최종 게이트](q1_006_v02_execution_gate.json)는 신규20+기존173=193검사 통과다. 초기 공통 집단·F0 고정 연결·F1 모듈 ID·순환/연산/범위 제한·교차 우성·scalar/batch 출력·환경 재생·역할 캐시·분할 접근·후보 잠금·중단/재개·자료 손상 거부·통계·모의 본/확인 집계를 포함한다. 실제 성능 결과로 이 검사를 고르지 않았다. pytest가 아니라 unittest와 기존 프로젝트 점검 도구를 사용했다.

## 예비와 비용

[예비 보고](../../studies/interaction/results_q1006_v02/pilot/cost_report.json)의8작업·5회차·20개체·훈련24목록은 총19,200에피소드다.2회차 중단 뒤 재개해 전체100개체/작업의 유전체·번식·선발·RNG·행동 재생이 일치했다. 미확정 작업0, 검증/테스트0호출, 성능 기반 조건 선택 없음.

추가 비용 표본은 초기 원형4개에24호출과756호출을 적용한 총3,120개의 훈련 전용 에피소드다. 본120작업의 순수 커널 시간 모형은2작업 병렬 기준 약874초, 보수적2배 계수는약1,748초다. 구조 성장·압축·감사·선발·게시 시간을 제외한 초기4모듈 모형이므로 전체 완료 시한이 아니다. [비용 도구](../../tools/cost_q1006_v02.py)와 원자료의 cost_projection.json에 보존했다. v0.1 표본과 합쳐 실제 추가 비용은6,240호출이며 본 예산에 합치지 않는다.
