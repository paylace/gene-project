# Q1-005 실행 준비·예비 검증

버전1.0 / 2026-10-16 한국 시간 / 구현 검사·훈련 전용 예비·본 비교 완료. 성능 결과 보고서와 구분한다.

## 설계 고정과 구현

[실험 계획](../protocols/Q1-005_보상과번식_실험계획.md)의 A0·네 보상/번식 조건과 공통 random을 구현했다. 이전 수치 초안보다 시드 반복을20개로 늘리고 조합 대비를 포함한 세 주 대비를 등록했다. 이는 새 성능을 보기 전 결정이며 [수치 JSON](../protocols/q1_005_v01_plan.json)에 고정했다.

새 패키지 `evosim_q1005_v01`의14개 Python 파일과 기존 동결 의존성20개를 함께 소스 지문으로 관리한다. 기존 v0.1·v0.2 Python 소스는 수정하지 않았다. 네트워크 구조·초기화·유전 연산은 A0이고 생애 학습은 없다. R1은 정책 입력·행동·환경 보상에 개입하지 않으며 번식 점수에만 거리 감소/60을 더한다. R1 총점은1/300 정수 단위로 합산하고 R0는 기존 합산을 유지한다. 판정 경계의1e-12 허용은 부동소수점 오차 처리다.

## 검사

[최종 게이트](q1_005_execution_gate_final.json)에서 **신규48+기존99=147개**를 통과했다. 이전46+99의 개발 게이트도 보존했으며, 예비 전에 정수 합산·수치 경계의 두 회귀 검사를 추가한 이유를 [개발 기록](q1_005_development.json)에 남겼다. 새 성능 결과에 따른 변경은 없다.

- R0의 기록·행동·점수와 기존 구현 일치. 순위값으로의 치환 후5회 번식의 유전체·부모·난수·ID도 일치.
- R1의 왕복 중복 방지·벽·실패 수집·목표 전환 예외와18단위=0.3 상한. 같은 개체의 R0/R1 행동·환경 보상 불변, scalar/batch 진행 보상 일치.
- 전체1,512조합의 알려진 좌표 규칙으로 원래 환경·진행 보상 재생의 정합성 확인.
- 네 조건·두 방법의 연속 실행과 중단/재개 일치. 원자료 저장 뒤 체크포인트 쓰기 실패를 주입하여 중복 계산 계수·파일 불변 확인.
- 네 조건 random의 유전체·검증 선발 일치. 본 실험에서는 공통 random 한 집단만 사용.
- 후보 잠금 전·다른 후보·부분 시험을 거부. 최종 평가 연결 fixture는 후보 시험 커널을 mock하고 알려진 좌표 규칙 기록으로 저장·재생만 검사.
- 같은 후보의 세 역할 캐시·재개, 기록 변조 거부, 완료/미확정 중단 작업의 실제 호출·상한, 단일 프로브 행동의 별도 계수.
- 합성20시드의 정확 부호 확률·Holm 세 대비·고정 확인 우선순위·효과 경계·최종 분석 구조.

자동 검사는 해당 사례의 동작을 확인한다. 모든 버그의 부재·과학적 독립 검토·성능 향상을 의미하지 않는다.

## 본 실행 중 발견한 검사 이식성 문제

GitHub Linux Python3.11.17에서 원본48검사 중 공통 random 전체 후보 사전 일치 검사1개가 실패했다. 3회차 verification fixture는 중간 회차에서 훈련 점수도 후보로 사용하므로 R1의 훈련 메타데이터까지 같다는 가정은 과도했다. 본·확인은 그 분기를 사용하지 않고 검증 전용으로 선발한다. 원본 소스·검사·게이트·원자료는 수정하지 않았다. 별도 `tools/check_q1005_portable.py`에서 원본47검사에 전체 검증 회차의 후보/행동 일치와 본 분기의 검증 전용 선발2검사를 더해49개 통과했다. [원인·범위 기록](q1_005_ci_portability.json)에 실패 실행 링크와 처리 범위를 남겼다. 최초147개 통과는 원래 Windows 런타임에서의 사실이며 Linux48개 통과로 확대하지 않는다.

## 공식 예비·추가 비용 표본

911/912 × 네 진화 조건+공통 random=10실행을 수행했다. 집단20·5회차·훈련24개이며2회차에서 중단한 뒤3회차를 재개했다.

- 계획·실제 완료: **24,000에피소드**. 미확정 중단 작업0건.
- 모든1,000개체 평가의 유전체·선발·유전 연산과 행동·진행 보상 재생 감사 통과.
- 검증·테스트: **0**. 예비 성적에 따른 조건·계수·판정 변경 없음.
- 두 worker 탐색·재개 약3.08초. 감사·보고·사전 준비는 별도.
- 당시 출력 약2.61MB. 본 원자료 크기의 보증이 아님.

원 기록은 `studies/interaction/results_q1005_v01/pilot/`에 있다. [비용 표본](q1_005_cost_projection.json)은 훈련 목록의24/756/1,512 batch 크기로 추가18,336에피소드를 계산했다. 첫 초기 개체와 사전에 만든9모듈 템플릿을 사용했으며 성적을 조건 선택에 쓰지 않았다. 이 추가 호출은 공식 예비24,000개에 합쳐 숨기지 않는다.

계산·저장 표본 모형의 본 비교 부분 비용은 약12~14분이고 감사·체크포인트·구조 성장·기계 부하를 고려한 계획 범위는 약16~42분이다. 정확한 ETA·신뢰구간이 아니다.
