# Q1-006 — 공통 템플릿 준비 검사

구분: 수작업 정책의 기술적 표현 가능성 검사. 실행2026-10-16, 문서 정리2026-10-17. 검사 완료·독립 검토 미완료. Q1-006 진화 본 실험과 구분한다.

## 목적과 방법

고정 구조 가중치 탐색 F0와 같은 시작점의 구조 변경 허용 F1을 비교하기 전에, 공통 출발 템플릿 안에 과제 해법이 존재하는지 확인했다. 기존 관측0~1 좌표와 환경7칸·3목표·24행동을 유지했다. 네 모듈은 모두 tanh, 순환 간선은 없고 입력→모듈16개·모듈→출력12개 연결을0가중치까지 명시했다.

위치 p·목표 g에 대해 m0=tanh(2p−2g), m1=tanh(−2p+2g), m2=tanh(0.1), m3=tanh(0)으로 구성했다. 왼쪽·오른쪽·수집 출력은 각각 m0·m1·m2를 읽고 나머지 연결은0이다. 모든 가중치는 기존 범위±3 안에 있다. 관측에 정답이나 미래 목표를 추가하지 않았다. 손으로 정한 가중치이며 향후 무작위 초기 집단에 이 정답을 심는다는 뜻은 아니다.

## 실제 결과와 해석 범위

전체1,512에피소드가 모두 최단 행동 수로 세 목표를 완료했다. 초기 상태441개에서 정답 방향315쌍·수집63상태 모두 유일 정답이었다. 새 진화 탐색은0회다. 이는 같은 benchmark를 다시 쓴 기술 검사이며 환경 일반화·진화의 발견 능력·생애 학습의 증거가 아니다. 에피소드1,512개·초기 상태441개는 Q1-009 호출 수와 별도로 계수한다.

호환성 때문에 기존 Settings("A0") 객체를 사용했지만 실제 구성 유전체는 tanh만 포함하고 순환이 없다. F0/F1의 변이·교차 제약을 구현하거나 검증한 것은 아니다. 초기화 분포·구조 제안 처리·평가 예산·시드·성공 판정은 개별 실행 전 계획에서 확정해야 한다. 검사 중 실패·수정은 기록되지 않았으며 모든 결함 부재의 증명은 아니다.
