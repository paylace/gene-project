## 문서의 역할

연구 목적은 전체 질문을, 계획은 다음 행동을, 프로토콜은 한 실험의 조건을, 보고서는 그 실험의 방법·결과·해석을 담는다. 결과가 나왔다고 목적이나 사전 조건을 소급해 고치지 않는다.

각 공식 보고서는 단독으로 읽어도 대상 과제, 지표, 비교 조건, 한계, 원자료와 수행 주체를 알 수 있게 작성한다. 새 결과는 해당 실험 보고서를 고치고 현황과 연구일지에는 요약·링크만 남긴다.
