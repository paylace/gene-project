연구별 실행 묶음 안의 상대 배치는 유지했다. 패키지 내부의 `results_v01/`을 바깥으로 옮겨 소스 해시·기존 명령을 바꾸는 대신, 연구 묶음을 한 번에 이동했다. 사람이 읽는 공식 보고서는 `docs/reports/`로 분리했다.

## 실행 디렉터리

| 연구 | 프로젝트 루트에서 이동할 폴더 | 실행 예 |
|---|---|---|
| 작업 기억 | `studies/working_memory/` | `python -m unittest discover -s tests -v` |
| 이동·수집 | `studies/interaction/` | `python -m unittest discover -s evosim_interaction/tests -v` |
| 원자료 감사 | `studies/interaction/` | `python audit_interaction.py evosim_interaction/results_v01` |

Python 별칭이 동작하지 않으면 이번 실행에 사용한 `C:\Users\thoma\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`로 대체한다. 재현 가능한 버전은 각 연구의 프로토콜에 기록되어 있다. 결과 확인을 위해 본 실험을 다시 실행할 필요는 없다.

상호작용 실험의 상세 명령은 [연구 실행 안내](../studies/interaction/README.md), 작업 기억 연구는 [기존 실행 안내](../studies/working_memory/README.md)를 따른다.

## 문서·배치 점검 명령

프로젝트 루트에서 `python tools/check_research_layout.py`를 실행하면 활성 링크·보고서 ID·마지막 수행 기록·완료 실행의 코드 해시를 검사한다. 새 보고서를 추가해도 고정된 개수에 맞추지 않고 ID와 필수 필드를 검사한다.

`python tools/check_research_layout.py --tests`는 위 검사와 함께 두 연구의 테스트를 새 작업 디렉터리에서 실행한다. 본 실험을 재실행하지 않으며 결과와 콘솔 기록은 `docs/management/`에 저장한다. 원본 이동 후 내용 보존만 다시 확인하려면 `python tools/reorganize_research.py verify`를 사용한다.
