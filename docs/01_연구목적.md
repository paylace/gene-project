# 연구 목적과 질문 체계

문서 역할: 연구 전체의 목적과 용어를 관리한다. 실행 조건은 연구별 계획, 결과는 실험별 보고서에서 관리한다.

> 개체들이 환경의 정보를 이용하여, 상황과 행동의 결과에 맞게 자신의 행동을 조정할 수 있는지 확인한다. 어떤 능력이 진화로 형성되고, 어떤 능력이 개체의 경험으로 달라지는지 구분한다.

작업 기억은 이 목표를 위한 한 가지 능력이다. 기억 정확도를 높이는 것 자체를 연구 전체의 성공으로 취급하지 않는다.

여기서 말하는 ‘지능처럼 행동한다’는 표현은 아직 연구 질문이다. 먼저 아래의 관찰 가능한 행동으로 나누고, 실험으로 확인한 범위 안에서만 결론을 내린다. 하나의 과제를 잘 풀었다고 일반적인 지능이 생겼다고 판단하지 않는다.

연구 전체의 진전은 점수 하나로 판정하지 않는다. 어떤 정보를 이용하는지, 행동이 상황에 맞는지, 경험 후 무엇이 달라지는지, 어느 조건까지 유지되는지를 각각 기록한다. 단순한 반응 규칙도 환경에 맞는 행동의 한 형태다. 그 규칙으로 설명되는 결과를 실패로 취급하지 않되, 계획·추론·생애 학습의 증거로 확대하지 않는다.

### 서로 구분할 변화의 시간 범위

| 범위 | 질문 | 구별해야 할 설명 |
|---|---|---|
| 즉각적인 반응 | 같은 개체가 현재 관측에 맞춰 다른 행동을 하는가? | 항상 같은 행동을 해도 유리한 환경인지 확인 |
| 에피소드 안의 조정 | 앞서 얻은 정보나 자신의 행동 결과를 이용하는가? | 기억, 현재 관측, 환경에 남긴 흔적의 기여를 구분 |
| 생애 중의 적응 | 같은 개체가 경험을 통해 행동을 개선하는가? | 일시적 상태 변화와 실제 학습을 구분 |
| 세대 간의 적응 | 선택·변이·교차를 거치며 집단이 개선되는가? | 초기 편향, 학습 결과 상속, 선발 효과를 구분 |
| 새 조건으로의 전이 | 선발에 사용하지 않은 조건에서도 행동이 유효한가? | 훈련 조건에 대한 특화와 구분 |

## 2. 큰 목표를 나눈 세부 목표

아래는 목표의 계층이다. 모든 항목을 한꺼번에 구현하거나, 무조건 이 순서대로 어려운 환경을 추가한다는 뜻은 아니다.

```text
최종 목표: 환경에 맞게 행동을 조정하는 개체
│
├─ A. 환경 정보를 실제로 이용한다
│  ├─ A1. 상황이 달라지면 행동도 적절하게 달라진다
│  └─ A2. 과거 정보가 필요할 때 이를 이용한다
│
├─ B. 행동의 결과를 이용한다
│  ├─ B1. 행동이 다음 상태나 기회에 영향을 주는 과제를 수행한다
│  └─ B2. 즉시 얻는 이익과 이후의 결과를 구분할 수 있다
│
├─ C. 변화에 적응한다
│  ├─ C1. 경험을 쌓은 같은 개체가 개선된다
│  ├─ C2. 환경 규칙이 바뀌면 행동을 다시 조정한다
│  └─ C3. 세대 간 개선과 생애 중 개선을 구분할 수 있다
│
├─ D. 익숙하지 않은 조건에서도 일부 능력을 유지한다
│  ├─ D1. 새 표본에서도 성능이 유지된다
│  └─ D2. 난이도나 환경 요소가 바뀌어도 유효한 행동이 남는다
│
└─ E. 능력의 원인을 설명할 수 있다
   ├─ E1. 초기 구조·진화·학습·기억의 기여를 구분한다
   └─ E2. 단순한 규칙이나 실험상의 정보 누출로 설명되는지 확인한다
```

## 이번까지의 질문과 연결

- WM 계열: 정해진 지연 분류 과제의 기억·생애 학습·구조 의존성을 확인했다.
- Q1 계열: 행동이 다음 상태를 바꾸는 과제에서 현재 관측에 맞춰 이동·수집하는지를 확인했다.
- 두 연구는 환경·입력·지표가 다르다. 정확도 82%와 완료율 0.18%를 같은 척도의 성능 변화로 비교하지 않는다.
