# 연구 계획과 점검 지점

후속 연구의 전체 순서는 [구조·보상·탐색·규모 분리 계획 Q1-R01](protocols/Q1_구조_보상_탐색_규모_후속연구계획.md)에 정리했다. 현재 구조 비교(Q1-004)를 먼저 완료하고, 보상·번식 기준(Q1-005) → 고정 구조의 가중치 탐색(Q1-006) → 필요 시 탐색 예산·표현 용량(Q1-007)을 따로 비교한다. 후속 단계는 아직 실행 프로토콜을 잠그지 않은 계획이며, 기존 Q1-004 조건은 변경하지 않는다.

현재 [Q1-004 v0.2 후속 실험 계획](protocols/Q1-004_v02_실험계획.md)의 W1~W6 구현·99개 검사와 W7 훈련 전용 예비12실행을 완료했다. 소스·본 프로토콜을 고정하고 본 비교60실행을 시작했다. 근거와 비용은 [실행 준비 검증](management/Q1-004_실행준비검증.md)에 기록한다. 본 비교 완료·후보 잠금·최종 평가 전에는 성능 개선을 판정하지 않는다.

## 큰 흐름

| 단계 | 해야 할 일 | 통과 근거 |
|---|---|---|
| 질문 설정 | 큰 목표에서 이번에 답할 질문 하나를 고른다 | 관찰할 행동·반증 조건·해석 한계 |
| 환경 설계 | 관측·행동·전이·보상·종료를 정의한다 | 손으로 따라갈 수 있는 예시와 기준 정책 |
| 평가 계획 | 비교 대상·분할·예산·선발·판정을 고정한다 | 실행 전 프로토콜과 버전 |
| 구현 검증 | 환경·정책·난수·동결·재개를 검사한다 | 자동 검사와 실패·수정 기록 |
| 예비 실행 | 별도 시드로 오류와 실행 비용을 확인한다 | 본 테스트를 사용하지 않은 예비 기록 |
| 본 실험 | 고정 조건의 모든 시드를 실행한다 | 정책·원자료·실패 실행·코드 해시 |
| 해석 | 사전 질문에 답하고 한계와 다음 질문을 정한다 | 본 결과와 사후 진단을 구분한 보고서 |

## 현재까지 완료

- WM-001~004: 작업 기억 본 비교와 세 종류의 후속 검사.
- Q1-000: 구현·측정 검증.
- Q1-001: 이동·수집 본 실험.
- Q1-002~003: 표현·기억 제거 및 이동·수집 보완의 사후 진단.

## 다음 연구의 우선 질문 — 아직 미실행

“필요한 이동 방향 선택이 현재 진화 과정에서 왜 충분히 형성되지 않는가?”

첫 비교는 기존 구조 A0, 출력 자기순환만 금지한 A1, 모든 기억을 금지한 A2의 재진화와 같은 예산의 무작위 개체 탐색이다. 조건·판정·예산 초안은 Q1-004 계획에 모았다. 양수 부호 편향과 자동 수집 과제는 이후 단계로 분리한다. 계획 검토·구현 검사·예비 비용 확인 뒤 실행 프로토콜을 잠근다. 기존 결과가 낮다는 이유로 같은 실험의 예산을 사후 연장하지 않는다.

## 점검 때 묻는 사항

실험 전에는 질문·바꾸는 요소·유지하는 요소·비교 기준·철회 조건을 확인한다. 실험 후에는 실제 행동·단순 규칙의 설명력·진화와 생애 학습의 구분·실패 범위·다음 질문을 점검한다.

작성 규칙은 [보고서 작성 규칙](rules/보고서_작성규칙.md)을 따른다. 진행 순서는 [연구일지](logs/연구일지.md)에 남긴다.
