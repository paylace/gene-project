# 연구 계획과 점검 지점

후속 연구의 전체 순서는 [구조·보상·탐색·규모 분리 계획 Q1-R01](protocols/Q1_구조_보상_탐색_규모_후속연구계획.md)에 정리했다. 구조 비교(Q1-004)를 완료했으며, 보상·번식 기준(Q1-005) → 고정 구조의 가중치 탐색(Q1-006) → 필요 시 탐색 예산·표현 용량(Q1-007)을 따로 비교한다. Q1-005·006은 완료했고 Q1-007의 수치 조건은 아직 초안이다. 기존 Q1-004 조건은 변경하지 않는다.

현재 [Q1-004 결과](reports/Q1-004_구조제약_재진화비교.md)를 완료했다. 99개 검사·훈련 전용 예비12실행 뒤 소스를 고정하여 본60·확인40실행과 감사를 수행했다. 본 비교 A1의 큰 평균 개선이 새 시드 확인에서는 재현되지 않아 개선 구조로 채택하지 않았다. 개별 유능한 정책을 안정적으로 찾는 문제가 남았다. 구현·예비 근거는 [실행 준비 검증](management/Q1-004_실행준비검증.md)에 보존한다.

## 큰 흐름

| 단계 | 해야 할 일 | 통과 근거 |
|---|---|---|
| 질문 설정 | 큰 목표에서 이번에 답할 질문 하나를 고른다 | 관찰할 행동·반증 조건·해석 한계 |
| 환경 설계 | 관측·행동·전이·보상·종료를 정의한다 | 손으로 따라갈 수 있는 예시와 기준 정책 |
| 평가 계획 | 비교 대상·분할·예산·선발·판정을 고정한다 | 실행 전 프로토콜과 버전 |
| 구현 검증 | 환경·정책·난수·동결·재개를 검사한다 | 자동 검사와 실패·수정 기록 |
| 예비 실행 | 별도 시드로 오류와 실행 비용을 확인한다 | 본 테스트를 사용하지 않은 예비 기록 |
| 본 실험 | 고정 조건의 모든 시드를 실행한다 | 정책·원자료·실패 실행·코드 해시 |
| 해석 | 사전 질문에 답하고 한계와 다음 질문을 정한다 | 본 결과와 사후 진단을 구분한 보고서 |

## 현재까지 완료

- WM-001~004: 작업 기억 본 비교와 세 종류의 후속 검사.
- Q1-000: 구현·측정 검증.
- Q1-001: 이동·수집 본 실험.
- Q1-002~003: 표현·기억 제거 및 이동·수집 보완의 사후 진단.
- Q1-004: 구조 제약 재진화 본60·새 시드 확인40실행·감사. A1 확인 기준 미충족, A2로 대상을 바꾸거나 시드를 추가하지 않음.
- Q1-005: 보상·번식 본100실행·감사 완료. 세 주 대비 모두 기준 미충족, 조건부 확인 미실행.
- Q1-006: 공통 tanh 템플릿 본120작업·감사 완료. F0 우세 기준 미충족, 확인·추가 시드 미실행.

## 완료 점검 — Q1-009 초기 반응·고착 요인 분리

[Q1-009 결과](reports/Q1-009_초기반응과고착_요인분리.md)는 초기500원형×4조건의 직접 효과 진단이다.173개 검사·훈련 전용 예비·비용 확인 뒤 동결 소스로 본 평가와 감사를 완료했다. 고착 감소에도 완료율은 매우 낮았으며 학습·진화·후보 선발은 하지 않았다. 이 진단을 Q1-006 기술 준비로 추가했고 기존 진화 비교 순서는 유지한다. 실행일은2026-10-16, 이 현황 정리는2026-10-17이다.

## 완료 점검 — Q1-006 고정 구조·구조 탐색 비교

[v0.2 개별 계획](protocols/Q1-006_v02_고정구조와구조탐색_실험계획.md)의 본40짝 시드·120작업과 전체 감사를 완료했다. [공식 결과](reports/Q1-006_고정구조와구조탐색_비교.md)는 F0 평균12.4008%, F1 평균22.1230%, 공통 무작위 탐색2.1627%다. 주 대비 F0−F1은−9.7222pp·개별95% 기술 구간−20.6897~+0.7495pp로 진행 기준 미충족이며 확인·추가 시드를 실행하지 않았다. F1의 우세를 확인한 결과로 바꾸어 해석하지 않는다.

80% 이상 후보를 찾은 시드는3/40·5/40·0/40이었다. 진화가 유능한 정책을 찾을 수 있으나 안정적인 발견은 남은 문제다. F1의 한8모듈 후보는 테스트100%이고 처음 좌표 규칙과 다른561회도 모두 완료했다. 초기 반응·과정 완수·생애 학습을 구분한다. v0.1 예비 오류는 원본 보존 후 새 버전으로 수정했고193검사·8예비 뒤 본을 진행했다. 세부 실패·호출 수·코드 지문은 보고서에 있다.

## 다음 점검 — Q1-007 실행 전 설계 구체화

다음 질문은 같은 표현과 방법 안에서 탐색 자원이 성공 발견 빈도를 높이는지다. 기존 [Q1-R01](protocols/Q1_구조_보상_탐색_규모_후속연구계획.md)의 집단 크기·회차 수 분리 원칙을 유지한다. Q1-006의 평균이 높은 F1을 자동으로 새 표준으로 삼거나, 이번에 낮은 시드만 더 돌리지 않는다.

먼저 Q1-006의 세대별 성능·발견 빈도·유효 변이와 [로그 진단](management/q1_006_log_diagnosis.json)을 검토한다. 마지막 회차의 고유 유전체 수는 집단20개 중 평균F0 6.35·F1 9.25였으나 이것이 행동 다양성이나 실패 원인이라는 증명은 아니다. 구조 부담을 줄이기만 하면 해결된다는 근거는 얻지 못했으므로, 규모 비교에 쓸 공통 구조·변이 방식과 대조를 먼저 명시한다.

[Q1-007 개별 계획 0.1](protocols/Q1-007_탐색예산_실험계획.md)에 고정4모듈 F0·집단20/40×회차100/200·새80쌍을 명시했다. F0는 용량을 일정하게 두기 위한 선택이며 우세 구조 채택이 아니다. 주 지표는 테스트 완료율80% 이상 후보를 찾은 시드 비율이다. PT−B의 단측·P−T의 양측 두 대응 이진 검정에 Holm과10pp 문턱을 적용한다. 무작위 탐색 대조는 기술적 보조다.

같은 예산 P/T는 훈련개체4,000·검증후보400개가 같다.100회차 접두 기록을 재사용하는 본은159,360,000탐색 에피소드 슬롯·테스트 최대846,720슬롯이다. [수치 초안](protocols/q1_007_v01_draft.json)과 [정책 호출0회의 설계 계산](management/q1_007_design_preview.json)을 보존했다. 모듈 수 증가는 별도 단계다.

**v0.1 구현·예비·비용 검증을 완료했으나 본은 보류했다.** [준비 결과](reports/Q1-007_탐색예산_비교.md)에 신규20검사·예비6작업76,800호출·훈련 분할 비용45,360호출과 감사를 기록했다. 기본 탐색/감사 약2.72시간,2배 시간상한5.44시간·비압축 JSON44.77GiB가 계획의4시간/20GiB를 넘었다. 실제 압축 파일 점유와 비압축 논리 부피를 구분하며 성능 효과는 미측정이다. 소스·당시 계획·비용 원본을 보존하고 다음 버전에서 손실 없는 저장 축소와 수치 동일 평가 묶음 처리를 먼저 설계한다. 새 버전 구현·본·확인은 아직 미실행이다.

[v0.2 기술 준비 계획](protocols/Q1-007_v02_저장과평가_준비계획.md)에 완전 복원·행동 동치·메모리와 저장량의 실제 의미·새 비용 정의를 검증할 순서를 작성했다. 이는 실행 완료 기록이 아니다.

## 점검 때 묻는 사항

실험 전에는 질문·바꾸는 요소·유지하는 요소·비교 기준·철회 조건을 확인한다. 실험 후에는 실제 행동·단순 규칙의 설명력·진화와 생애 학습의 구분·실패 범위·다음 질문을 점검한다.

작성 규칙은 [보고서 작성 규칙](rules/보고서_작성규칙.md)을 따른다. 진행 순서는 [연구일지](logs/연구일지.md)에 남긴다.
