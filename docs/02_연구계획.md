# 연구 계획과 점검 지점

후속 연구의 전체 순서는 [구조·보상·탐색·규모 분리 계획 Q1-R01](protocols/Q1_구조_보상_탐색_규모_후속연구계획.md)에 정리했다. 구조 비교(Q1-004)를 완료했으며, 보상·번식 기준(Q1-005) → 고정 구조의 가중치 탐색(Q1-006) → 필요 시 탐색 예산·표현 용량(Q1-007)을 따로 비교한다. Q1-005는 개별 실행 프로토콜을 고정했고 Q1-006 이후는 초안이다. 기존 Q1-004 조건은 변경하지 않는다.

현재 [Q1-004 결과](reports/Q1-004_구조제약_재진화비교.md)를 완료했다. 99개 검사·훈련 전용 예비12실행 뒤 소스를 고정하여 본60·확인40실행과 감사를 수행했다. 본 비교 A1의 큰 평균 개선이 새 시드 확인에서는 재현되지 않아 개선 구조로 채택하지 않았다. 개별 유능한 정책을 안정적으로 찾는 문제가 남았다. 구현·예비 근거는 [실행 준비 검증](management/Q1-004_실행준비검증.md)에 보존한다.

## 큰 흐름

| 단계 | 해야 할 일 | 통과 근거 |
|---|---|---|
| 질문 설정 | 큰 목표에서 이번에 답할 질문 하나를 고른다 | 관찰할 행동·반증 조건·해석 한계 |
| 환경 설계 | 관측·행동·전이·보상·종료를 정의한다 | 손으로 따라갈 수 있는 예시와 기준 정책 |
| 평가 계획 | 비교 대상·분할·예산·선발·판정을 고정한다 | 실행 전 프로토콜과 버전 |
| 구현 검증 | 환경·정책·난수·동결·재개를 검사한다 | 자동 검사와 실패·수정 기록 |
| 예비 실행 | 별도 시드로 오류와 실행 비용을 확인한다 | 본 테스트를 사용하지 않은 예비 기록 |
| 본 실험 | 고정 조건의 모든 시드를 실행한다 | 정책·원자료·실패 실행·코드 해시 |
| 해석 | 사전 질문에 답하고 한계와 다음 질문을 정한다 | 본 결과와 사후 진단을 구분한 보고서 |

## 현재까지 완료

- WM-001~004: 작업 기억 본 비교와 세 종류의 후속 검사.
- Q1-000: 구현·측정 검증.
- Q1-001: 이동·수집 본 실험.
- Q1-002~003: 표현·기억 제거 및 이동·수집 보완의 사후 진단.
- Q1-004: 구조 제약 재진화 본60·새 시드 확인40실행·감사. A1 확인 기준 미충족, A2로 대상을 바꾸거나 시드를 추가하지 않음.
- Q1-005: 보상·번식 본100실행·감사 완료. 세 주 대비 모두 기준 미충족, 조건부 확인 미실행.

## 완료 점검 — Q1-009 초기 반응·고착 요인 분리

[Q1-009 결과](reports/Q1-009_초기반응과고착_요인분리.md)는 초기500원형×4조건의 직접 효과 진단이다.173개 검사·훈련 전용 예비·비용 확인 뒤 동결 소스로 본 평가와 감사를 완료했다. 고착 감소에도 완료율은 매우 낮았으며 학습·진화·후보 선발은 하지 않았다. 이 진단을 Q1-006 기술 준비로 추가했고 기존 진화 비교 순서는 유지한다. 실행일은2026-10-16, 이 현황 정리는2026-10-17이다.

## 현재 점검 — Q1-006 구현·실행 준비

[Q1-005](reports/Q1-005_보상과번식_분리비교.md)의 보상·번식2×2 본100실행과 감사를 완료했다. 세 주 대비 모두 진행 기준을 충족하지 않아 확인·추가 시드를 실행하지 않았다. 보상 변경만으로 안정적인 개선을 확인하지 못했으며 이 결과를 규모 부족이나 구조 전체의 불가능성으로 해석하지 않는다.

다음은 Q1-R01의 고정 구조 가중치 탐색과 구조 변경 허용 비교다. 같은 시작 템플릿·기존 R0/S0·같은 관측과 유전 연산 범위를 명시하고, 해결 가능성·무효 변이·실제 비용·시드·평가·확인 기준을 먼저 고정한다. Q1-006은 아직 개별 실행 전 초안이며 진화 본 실행은 미실행이다. [준비 검사](management/Q1-006_템플릿_준비검사.md)는 원래 좌표0~1·순환 없는4모듈 tanh·범위 내 수작업 가중치로 전체1,512조합의 최단 해결을 확인했다. F0/F1용 탐색 연산은 아직 구현하지 않았다. Q1-005의 사후 최고 조건으로 보상·구조를 동시에 바꾸지 않는다.

### 다음 작업의 순서와 종료 지점

1. **비교를 명세한다.** F0는 고정 연결의 가중치·편향만, F1은 같은 초기 집단에서 구조 변경도 허용한다. 두 조건 모두 같은 tanh·순환 금지·기존 관측과 R0/S0를 사용한다. Q1-009의 최고 조건을 자동으로 결합하지 않는다.
2. **판정을 먼저 정한다.** 평균 완료율을 주 지표로 두고, 사전에 정한 높은 완료율에 도달하는 독립 탐색 시드 비율·첫 발견 비용을 함께 보고한다. 높은 완료율의 문턱과 다중 지표의 역할은 본 결과 전에 고정한다. 희소하고 양극화된 결과를 가정한 모의 자료로 판정 규칙과 표본 수를 점검한다.
3. **연산·평가를 검증한다.** 구조 제안·무효 제안·실제 변경을 따로 센다. F0의 금지 구조 제안이 no-op인 주 비교는 같은 제안·평가 예산의 비교이며 유효 변이 수가 같은 비교라고 부르지 않는다. 훈련·선발·테스트와 후보 잠금·재개를 검사한다.
4. **별도 예비 뒤 프로토콜을 잠근다.** 새 시드·정해진 실행 수·평가 호출·원자료 크기·확인/중단 규칙을 확정한 뒤 본 비교를 실행한다. 성능을 보고 조건·예산을 조정하면 별도 버전으로 기록한다.
5. **결과를 해석한다.** F0만 안정적으로 개선되면 이 예산에서 구조 탐색 부담을 의심한다. 둘 다 개선되면 가중치 탐색의 가능성을 확인하고 안정성과 비용을 비교한다. 둘 다 낮으면 적합도 신호·변이 크기·다양성·수치 동작을 점검한 후 규모 실험 여부를 정한다. 단순히 더 크게 돌리는 것으로 넘어가지 않는다.

현 단계는 [개별 계획v0.2](protocols/Q1-006_v02_고정구조와구조탐색_실험계획.md)에 따른 구현·예비 검증이다. v0.1 예비의 작업 수 오류는 보존하고 새 버전에서 수정했다. 본 비교는 게이트·예비·비용 확인 뒤 진행한다. 위 문장은 연구 설계 방향이며 아직 시드 수·실행 예산·진행 문턱을 확정한 실행 명세는 아니다.

## 점검 때 묻는 사항

실험 전에는 질문·바꾸는 요소·유지하는 요소·비교 기준·철회 조건을 확인한다. 실험 후에는 실제 행동·단순 규칙의 설명력·진화와 생애 학습의 구분·실패 범위·다음 질문을 점검한다.

작성 규칙은 [보고서 작성 규칙](rules/보고서_작성규칙.md)을 따른다. 진행 순서는 [연구일지](logs/연구일지.md)에 남긴다.
