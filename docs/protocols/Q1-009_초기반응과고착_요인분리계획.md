# Q1-009 — 초기 반응과 반복 고착의 요인 분리 계획

버전 1.1 / 2026-10-16 한국 시간 / 새 조건 실행 전 설계. Q1-008 이후의 사후 가설을 다루는 탐색적 개입 진단이며, 진화 성능의 확인 실험이 아니다.

## 질문과 범위

같은 초기 유전체에서 좌표 입력의 중심화와 출력 자기순환 제거가 올바른 즉시 반응 및 반복 고착에 미치는 영향을 분리한다. Q1-008 교차 검토에서 발견한 반응성 측정 문제를 먼저 수정한다. 학습·번식·후보 선발은 없다. 기존 환경과 원래 보상·종료 규칙을 유지한다. 이 결과만으로 어느 설계가 진화에 유리한지 판단하지 않는다.

| 조건 | 위치·목표 입력 | 출력 자기순환 |
|---|---|---|
| C0N0 | 기존 0~1 | 초기 A0 그대로 |
| C1N0 | 위치·목표만 2x−1 | 초기 A0 그대로 |
| C0N1 | 기존 0~1 | 해당 간선만 제거 |
| C1N1 | 위치·목표만 2x−1 | 해당 간선만 제거 |

남은 목표·행동 비율은 그대로다. 목표−위치 특징을 추가하지 않는다. 모듈 연산·모듈 기억·기타 순환·나머지 가중치는 같은 원형에서 유지한다. N1은 간선 제거이고 생애 학습은 없다. 생애 학습 OFF인 기존 A0 설정과 정책 계산을 재사용한다.

## 표본과 고정 예산

- 본: 초기 유전체 시드 6000~6499의 **500개**. 유전체가 짝 비교의 단위다.
- 예비: 시드 5900/5901, 훈련 목록의 앞 24개만 사용해 비용과 저장·재개를 확인한다. 예비 성적을 설계 변경에 사용하지 않는다.
- 본 환경 목록: 기존 전체 1,512조합, 조건당 1회. 조건 이름을 제외한 같은 난수 파생 규칙을 사용한다. 이미 관측한 benchmark를 재사용하는 진단이다.
- 본 에피소드: 500×4×1,512=**3,024,000**. 예비 에피소드 192개는 별도다.
- 추가 비용 표본: 예비 두 원형의 훈련 756개×2반복×4조건=12,096에피소드로 본과 같은 열 크기·프로브·압축·감사 비용을 측정한다. 단일 상태와 감사 재계산 각각3,528개는 별도다. 시간·저장만 확인하고 성적을 설계에 쓰지 않는다. 실행 전 비용 모형 구체화를 반영한1.1개정이다.
- 고정 대조: 입력 무관 동률, 항상 왼쪽, 항상 오른쪽, 항상 수집, 범위 안 4모듈 수작업 정답 정책의 5개×4조건×1,512=**30,240**. 이 대조는 독립적인 탐색 시드가 아니다.

## 수정한 반응성 검사

내부 상태를 0으로 고정한 상태에서 위치 7×목표 7×남은 목표 수 3×남은 행동 수 {1,12,24}=**441상태**를 평가한다. 이 조합은 실제 방문 빈도를 대표하지 않는 균등한 가상 상태 검사다.

동결 정책이 사용하는 softmax 확률의 최댓값·동률 판정 집합을 그대로 계산한다. 동률 선택은 집합 안 균등 확률이므로 정답의 선택 확률을 해석적으로 기록한다. 서로 다른 난수 소비를 입력 효과로 세지 않는다.

- 좌우 전환 쌍: 같은 위치에서 왼쪽 목표와 오른쪽 목표를 모두 조합한다. 35쌍×3목표 수×3행동 수=**315쌍**. 양쪽 모두 정답을 유일하게 선택한 쌍의 비율을 기록한다. 입력 무관 동률 정책·상수 정책은 0이어야 한다.
- 수집 상태: 위치=목표인 7×3×3=**63상태**의 유일 정답 비율·정답 동률 확률을 별도로 기록한다.
- 전체 441상태의 정답 동률 확률 평균도 보고한다. 방향 상태와 수집 상태의 분모를 섞어 반응성 하나로 해석하지 않는다.
- 좌우 쌍의 두 분기는 동일한 초기 내부 상태를 사용한다. 출력 자기순환 제거는 첫 스텝에 영향을 주지 않으므로 C가 같으면 N0/N1의 첫 스텝 기록이 일치해야 한다.
- 본 단일 상태 계산 500×4×441=**882,000**. 고정 대조 8,820개와 예비 3,528개는 별도다. 좌우 쌍은 위 단일 상태 결과를 재사용한다. 감사에서는 같은 단일 상태 출력을 한 번 더 계산하므로 본 882,000·대조 8,820·예비 3,528 상태 계산이 별도로 추가된다.

## 에피소드 지표와 해석

주 진단 지표는 **전체 에피소드 중 마지막 6행동이 모두 벽 충돌 또는 모두 실패 수집인 반복 고착의 비율**이다. 마지막 6행동이 같은지도 요구한다. 6행동보다 짧게 끝난 경우는 해당 없음으로서 고착 0이다. 실패 에피소드만을 분모로 삼지 않는다. 엄밀한 흡수 상태라고 부르지 않는다.

보조 지표는 세 목표 완료율, 원래 평균 보상, 수집 수, 벽 충돌·실패 수집, 끝 6행동 동일, 첫 오답 뒤 회복, 목표 전환 직후 정답, 에피소드 최대 출력 크기, 수정한 초기 반응성이다. 출력 최대값은 유한한 24행동 안의 값이며 무한 발산 판정이 아니다.

세 대비 C1N0−C0N0, C0N1−C0N0, C1N1−C0N0와 상호작용을 실행 전에 지정한다. 평균·중앙값·표준편차·짝 차이의 양수/음수/동률 수와 전체 시드 자료를 남긴다. 같은 500짝 시드의 bootstrap 10,000회, 난수 72009, 개별 95% 백분위 구간을 기술적으로 보고한다. 동시 구간·가설 검정·진화 개선 채택 기준으로 사용하지 않는다. 결과를 보고 표본 수·주 지표·환경을 바꾸거나 확인을 추가하지 않는다.

## 실행·보존·오류 처리

기존 동결 소스를 수정하지 않고 `evosim_q1009_v01/`과 `results_q1009_v01/`을 사용한다. 원형 유전체, 변환 유전체, 모든 에피소드 행동·보상, 단일 상태 출력·동률 집합, 정수 집계를 저장한다. 실제 정책 선택과 scalar/batch 정합성, 고정 대조, 고착 분류, 유전체 불변, 변조·재개 거부를 검사한 뒤 실행 게이트를 저장한다. 완료한 자료는 덮어쓰지 않는다.

소스·수치 계획·전체 목록·런타임·게이트·예비 지문을 실행 명세에 잠근다. 실행별 UUID 작업 원장으로 완료 호출과 미확정 중단 상한을 구분한다. 결과 저장 후 중단 시 캐시를 검증해 재사용한다. 원자료의 행동으로 보상·종료·고착·진단 값을 재생하여 감사한다. 일부 scalar 대조만으로 모든 신경망 행동을 재계산했다고 주장하지 않는다.

실제 기술 오류가 나면 실패를 보존한다. 실행 소스나 조건 변경은 새 버전으로 처리한다. 예비 비용이 본 예상 저장 2GB 또는 탐색 시간 30분을 넘으면 본 실행을 시작하지 않고 비용 판단을 남긴다. 이 상한은 성능에 따른 중단 기준이 아니다.
