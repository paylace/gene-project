# Q1-011 — 평가·저장 통합 경로 추가 점검

작성일: 2026-10-17. 첫 벤치마크의 평가 개선과 저장 병목을 확인한 뒤 작성한 기술 보완이다. 본 성능 판정과 무관하다.

별도 버전 파일 `studies/interaction/experiment_runtime_v01.py`에서 기존 평가+gzip3(reference), 묶음 평가+관측 열 gzip9(balanced), 묶음 평가+재생형 기록(archive)을 명시적인 프로필로 조합한다. 기존 완료 소스는 수정하지 않는다. 기본 제안인 balanced의 전체 경로가 이득인지 실제 측정한다.

조건은 기존 벤치마크의 훈련 분할·초기화·목적 문자열을 유지한다. 집단20/40×훈련24개는 reference/balanced 각각3회, 집단20×훈련252개×3반복은 각각2회로 제한한다. 추가 정책 호출은69,120, 앞선288,378과 합쳐357,498이다. 원래 총 상한380,800과 별도 fixture 상한100,000을 넘지 않는다. 새 조건은 평가 성능을 보고 선택한 과학적 비교가 아니라 작은/큰 배치의 기술 비용 확인이며, 두 번의 큰 사례를 정밀한 속도 추정으로 취급하지 않는다.

각 실행은 별도 프로세스에서 평가→실제 파일 저장/fsync→읽기/복원/원본 비교를 수행한다. 실행별 단계 시간·전체 시간·파일 크기·메모리·결과 해시·호출 수를 남긴다. 모든 기록과 실제 지표가 같아야 한다. 저장 옵션이 과학적 결과를 바꾸면 채택하지 않는다. 출력은 `optimization_q1011_pipeline_v01/`에 보존한다.

프로필 기본값은 검증된 기술용 API의 제안이며 본 실행기를 대체하지 않는다. 실제80시드 실험은 별도 전체 비용 게이트와 접근/후보 잠금 검증을 거쳐야 한다.
