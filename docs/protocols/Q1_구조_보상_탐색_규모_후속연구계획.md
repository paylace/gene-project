## 1. 현재 근거와 아직 모르는 것

[Q1-001](../reports/Q1-001_이동수집_본실험.md)에서 진화 완료율은 0.1786%, 같은 예산의 무작위 개체 탐색은 0.1521%, 무작위 행동은 1.0516%였다. 현재 조합의 탐색 성과는 낮으며, 진화의 추가 이득도 확인하지 못했다. 단순히 더 크게·오래 실행하면 해결될 것이라고 전제하지 않는다.

[Q1-002](../reports/Q1-002_표현과기억_진단.md)의 수작업 네 모듈 신경망은 전체1,512조합을 해결했다. 현재 과제의 해결책을 표현할 수 있다는 근거이며, 진화가 그 해결책을 발견할 수 있다는 증명은 아니다. 일반적인 지능이나 복잡한 새 과제까지 표현할 수 있다는 결론도 아니다.

[Q1-003](../reports/Q1-003_행동병목_진단.md)에서 정답 이동을 보완하면 완료율이66.25%로 높아졌다. 이동 방향 선택의 병목을 시사하지만, 외부 보완의 성적이며 원인을 완전히 분리한 인과 효과가 아니다.

현시점의 작업 가설은 **표현 용량 부족보다 탐색 방식·보상·초기 구조의 상호작용을 먼저 의심한다**는 것이다. 주원인 확정이나 확률 순위가 아니다. 네트워크 크기, 집단 크기, 회차 수를 따로 바꾼 실험은 아직 없다.

## Q1-004 완료 후 점검

[구조 비교 결과](../reports/Q1-004_구조제약_재진화비교.md)에서 본 비교의 A1 평균 개선은 새 시드에서 재현되지 않았다. A2의 단일100% 후보와 확인 A0의61.31% 후보는 해결 가능한 정책이 실제 진화로 발견될 수 있음을 보여 주지만, 안정적인 발견은 미해결이다. A1을 개선 구조로 확정하거나 A2 확인을 추가하지 않는다. 기존 순서대로 보상·번식 기준 분리의 개별 프로토콜을 준비하며 A0 대조 원칙은 유지한다. 초기 상태 즉시 반응 프로브와 과정 전체 완수의 차이도 후속 측정에 반영한다. 이 개정에서 Q1-005 이후의 조건·예산을 잠그거나 실행하지 않았다.

## 3. 1단계 — 현재 구조 비교를 완료한다

[Q1-004 계획](Q1-004_v02_실험계획.md)과 [구현 명세](Q1-004_v02_구현명세.md)의 A0/A1/A2, evolution/random, 시드·예산·평가·주 지표·다중 비교·확인 규칙을 유지한다. 이번 후속 계획을 이유로 Q1-004의 보상이나 번식 기준을 바꾸지 않는다.

W3 평가기·관찰기, W4 탐색·후보 잠금·재개, W5 분석·감사, W6 정합성을 구현·검증한다. 그 뒤 예비 비용 확인과 프로토콜 잠금, 본 비교60실행, 후보 잠금 뒤 테스트를 수행한다. 예약 확인40실행은 기존 사전 기준을 통과할 때만 진행한다.

진행 기준은 기존 계획의 기준을 그대로 사용한다. 통과하지 못해도 보상·탐색 진단으로 이동할 수 있다. 그 경우 ‘구조 효과를 확인하지 못함’이라고 기록하며 A1/A2를 개선 구조로 확정하지 않는다. 이 단계가 끝나기 전에는 새 보상 조건의 성능을 미리 탐색하지 않는다.

## 4. 2단계 — 보상과 번식 기준을 분리한다

현재는 번식에 훈련 평균 보상을 쓰지만 주 성과는 세 목표 완료율이다. 두 기준이 같은 개체를 선호하는지 검사한다. 아래는 작동 원리 설명용 가정이며 실제 관측값이 아니다.

- 매번 목표 하나를 수집하고24스텝 종료: 평균 보상0.76, 완료율0%.
- 20%에서12스텝 완수, 나머지에서0개·24스텝 종료: 평균 보상0.384, 완료율20%.

이 예에서는 기존 보상이 첫 정책을 번식에 선호한다. 모든 부분 보상이 잘못됐다는 뜻은 아니며 실제 집단에서 이런 선호가 얼마나 발생하는지 함께 기록한다.

### 비교 초안

| 요소 | 대조 | 변경 후보 |
|---|---|---|
| 보상 R | R0: 기존 수집+1·매 행동−0.01 | R1: R0에 목표 접근의 제한된 진행 보상 추가 |
| 번식 기준 S | S0: 훈련 평균 보상 | S1: 훈련 완료율 우선, 평균 보상 차순위 |

R0S0/R1S0/R0S1/R1S1을 비교한다. 구조는 **A0로 고정**한다. Q1-004 결과에서 가장 좋아 보이는 구조로 바꾸지 않아 보상 효과와 구조 선택을 섞지 않는다. 생애 학습은 계속 끈다. 최종 후보 선발은 모든 조건에서 동일한 검증 완료율·기존 보상 기준으로 하고, 테스트도 기존 환경의 완료율을 주 지표로 삼는다. 훈련 중 shaping 점수를 최종 능력 점수로 보고하지 않는다.

R1 후보는 각 현재 목표에 대해 방문한 최소 거리를 추적하고, 이동으로 그 최소 거리를 새로 줄였을 때만 `η × 감소거리/6`을 준다. η=0.1은 잠금 전 후보값이다. 수집 후 새 목표의 최소 거리는 현재 거리로 초기화하며 그 초기화에는 보너스를 주지 않는다. 왕복 이동으로 같은 진전을 반복 보상하지 않는다. 이 정보는 보상 계산용이고 정책 입력에는 추가하지 않는다. 기존 입력·전이·종료·수집 보상은 유지한다.

개별 프로토콜을 잠그기 전에 다음을 검사한다.

- 왕복 이동·벽 충돌·실패 수집·목표 전환·시간 종료로 보너스를 반복 획득하지 않는가?
- 접근 보상 합이 의도한 상한 안에 있고 실제 완수와 진행 행동을 어떻게 순위화하는가?
- 완전한 에피소드 보상 합산에서 변화가 상쇄되어 기존과 모든 순위가 같은 무효 조작은 아닌가? 특히 망원합으로 소거되는 거리 potential을 넣고 탐색 효과를 기대하지 않는다.
- 훈련 선발만 달라지고 후보 선발·최종 평가가 공통으로 유지되는가?

단순 이동→한 목표 수집→세 목표 순서의 과제 분해·난도 조정은 이2×2 비교에 섞지 않는다. 필요하면 별도 탐색적 환경 진단으로 새 번호·프로토콜을 만든다.

## 5. 3단계 — 고정 구조에서 가중치 탐색을 검사한다

네 모듈 규모의 단순 순방향 템플릿을 먼저 명시하고, 그 템플릿 안에 해결 가능한 정책이 있는지 정합성 검사로 확인한다. 미래 목표를 입력에 넣거나 관측으로 정답 행동을 직접 제공하지 않는다.

두 조건은 같은 템플릿과 초기 가중치 집단에서 출발한다.

- F0: 모듈·연결·연산 종류를 고정하고 가중치·편향만 탐색한다.
- F1: 같은 시작점에서 모듈·연결 변경도 허용한다. 구조 변경의 효과를 보기 위한 주 비교에서는 두 조건의 연산 종류와 순환 허용 여부를 동일하게 고정한다.

현재 잠정안은 두 조건 모두 순환 없는 tanh 템플릿이다. 전체 A0와 F0를 곧바로 비교해 구조 자유도만의 효과라고 부르지 않는다. 템플릿·초기 가중치 분포·허용 연산은 실행 전 개별 프로토콜로 확정한다.

보상·번식 기준은 우선 기존 R0/S0로 두어 앞 단계의 사후 최고 조합을 무조건 가져오지 않는다. 개선 보상과 결합하는 실험이 필요하면 별도 확인으로 구분한다.

변이 제안 시도 예산, 실제 가중치 변경 수, 구조 변경 수, 무효율과 비용을 함께 기록한다. F0의 금지 구조 제안을 no-op으로 남기는 주 비교에서는 ‘같은 제안/평가 예산의 탐색 방식 비교’로 해석한다. 두 조건의 유효 변이 수까지 같다고 주장하지 않는다. 가중치 변이에 예산을 재분배하는 비교는 별도 보조 조건으로 사전 등록한다.

F0가 성공하면 현재 크기의 표현 능력과 제한된 탐색 가능성을 뒷받침한다. F0가 F1보다 좋으면 구조 탐색 부담의 근거가 되지만 모든 구조 진화 방식의 불가능성을 뜻하지 않는다. 둘 다 실패하면 크기 부족으로 바로 결론 내리지 않고 가중치 탐색·적합도 신호·수치 동작을 재점검한다.

## 6. 4단계 — 탐색 예산과 표현 용량을 따로 검사한다

이 단계는 ‘결과가 낮으니 더 돌리기’가 아니다. 별도 프로토콜과 새 탐색 시드에서 미리 정한 범위만 비교한다. 앞 단계에 기술 오류가 남아 있거나 모든 조건이 실패해 해석 가능한 비교가 없으면 확장을 보류하고 알고리즘/측정 검토로 돌아간다.

### 4A. 탐색 예산

네트워크 크기를 고정하고 집단20/40 × 회차100/200의2×2를 후보로 둔다. 같은 초기 집단을 공통 부분으로 만들 수 있는 범위와 추가 개체 생성 규칙을 고정한다. 평가 회차의 절대 위치·간격과 후보 선발 기회의 증가를 명시한다. 결과는 ‘주어진 전체 탐색·선발 예산의 효과’이며 세대 수만의 순수 효과로 해석하지 않는다.

최종 성능뿐 아니라 동일 누적 평가 수에서의 학습 곡선, 성공 시드 비율, 첫 유효 정책 발견 시점, 실제 시간·메모리·파일 크기를 보고한다. 초기 개체 수와 새로 평가한 개체 수를 세어 엘리트 재평가·캐시를 구분한다.

### 4B. 표현 용량

4A 이후 필요성이 남을 때 고정 구조의 모듈4/8을 후보로 비교한다. 집단·회차·환경·보상·선발 규칙을 고정하고 매개변수 수를 기록한다. 큰 구조가 같은 에피소드 수를 평가해도 계산 비용은 더 들 수 있으므로 동일 계산량 비교라고 부르지 않는다.

4모듈 해결책이 이미 존재한다는 사실을 함께 보고한다. 큰 구조의 개선은 ‘최소 용량이 부족했다’는 증명보다 탐색 용이성·여유 표현의 효과일 수 있다. 이 한 과제에서의 크기 비교를 일반 지능의 규모 법칙으로 확대하지 않는다.

## 7. 공통 평가·예산·진행 규칙

Q1-004의 확정 조건은 그대로 둔다. **아래 규칙은 Q1-005 이후의 개별 사전 프로토콜을 작성할 때 사용할 초안**이다.

1. 기본 환경·관측·행동·24스텝은 유지하고, 각 단계에서 변경한 요소를 명시한다. 같은 benchmark를 이미 보았다는 사실을 표시한다. 새 탐색 시드는 새 환경 일반화가 아니다.
2. 단계마다 원칙적으로 새 짝 시드10개를 사용한다. 시드 범위·조건 목록·초기화 대응·난수 파생·재개 식별자를 성능 확인 전에 잠근다. 이전 단계의 우수 시드만 골라 쓰지 않는다.
3. 주 지표는 동결 후보의 세 목표 완료율, 표본 단위는 탐색 시드다. 평균 수집 수·관측 반응·반복 행동은 보조 지표다. 자동 코드 검사 통과와 능력 향상을 구분한다.
4. 미래 단계의 기본 실질 차이 후보는10%포인트다. 주 대비를 실행 전에 제한하고, 짝 차이·구간·양수 시드 수를 보고한다. 유의성 주장을 할 경우 사전 정의한 대비군의 정확 부호 검정/Holm과 표본 수를 고정한다. 통계 검정 대상이 평균인지 시드 개선 확률인지 명시한다. Q1-004의 두 대비 기준을 여러 단계 전체에 적용한 보정으로 오해하지 않는다.
5. 주 대비 초안은 Q1-005의 R1S0−R0S0 / R0S1−R0S0 두 개, Q1-006의 F0−F1 한 개다. R1S1의 상호작용과 모든 부수 비교는 별도 명시한다. Q1-007은 진행 여부를 정할 때 비교군과 통계 계획을 함께 잠근다.
6. 효과를 찾지 못하면 해당 조건·예산에서 근거 부족이라고 기록한다. 동등성·불가능성으로 바꾸어 말하지 않는다. 새로운 조건을 고른 뒤 새 시드에서 확인하며, 확인 실패 후 다음 후보로 바꿔 성공할 때까지 반복하지 않는다.
7. 후보 전원·blind를 잠근 뒤 테스트를 연다. 테스트 점수로 후보·조건·지표를 재선발하지 않는다. 보상 비교에서는 최종 평가를 기존 환경으로 공통화한다.
8. 새 단계의 소스·프로토콜·분할·보상/선발 함수·설정·명령·라이브러리 버전을 해시로 잠근다. 각 단계는 새 출력 경로를 사용하고 이전 원자료를 수정하지 않는다.

Q1-005의4조건, Q1-006의2조건, Q1-007의 최대 후보 그리드는 연구 설계 초안이다. 아직 전체 실행 작업 수·검증 일정·대조 방법·확인 작업·원자료 크기를 확정하지 않았으므로 **후속 단계의 총 예산·ETA를 확정값으로 제시하지 않는다.** 각 실행 전 훈련/검증/테스트의 논리 슬롯·실제 호출·기준선·프로브·로그 재생 비용을 산출하고, 훈련 전용 예비로 비용을 확인한 뒤 잠근다.

## 8. 결과에 따른 방향 판단과 종료

| 결과 | 허용되는 판단 | 다음 행동 |
|---|---|---|
| 구조 제한만으로 일관된 개선 | 현재 제약의 탐색 효과를 지지 | 별도 시드 확인 후 보상 진단 |
| 보상/번식 기준 변경으로 개선 | 적합도 신호가 현재 성과를 제한했을 가능성 | 원래 환경 평가·확인, 구조와의 결합은 별도 비교 |
| 고정 구조만 개선 | 구조 자유도가 현재 탐색에 부담일 가능성 | 가중치 탐색과 구조 진화의 역할 재설계 |
| 예산 증가에 따라 개선 | 현재 범위의 탐색 자원 의존성 | 비용 대비 효과 판단, 무제한 연장 금지 |
| 큰 구조만 개선 | 더 큰 표현이 탐색/해결에 유리한 가능성 | 최소 용량 부족과 탐색 용이성 분리 |
| 여러 분리 비교에서도 개선 근거 부족 | 현재 방법을 계속 확대할 근거가 약함 | 탐색 알고리즘·다양성 보존·개체 설계의 근본 변경 검토 |

검증 실패·조건 누출·재개 불일치는 성능 결과와 분리하고 실패 기록을 보존한다. 일반 지능의 탄생·진화 접근 전체의 불가능성을 이 과제로 판정하지 않는다. 다음 대규모 계산 전에 현재까지의 근거·비용·미해결 질문을 한 번씩 검토한다.
