## 1. 바꾸는 것과 유지하는 것

모든 조건은 기존 A0 신경망·초기화·변이·교차·집단20·100회차·회차당 훈련24개를 사용한다. 일곱 칸·세 목표·24행동·네 입력·세 행동·종료·기존 보상은 유지한다. 생애 학습은 OFF다. 조건마다 처음부터 진화하며 같은 시드의 최초 집단은 동일하다.

| 조건 | 번식용 훈련 점수 | 번식 우선순위 |
|---|---|---|
| R0S0 | 기존 수집+1·행동−0.01 | 평균 훈련 점수 |
| R1S0 | 기존 보상+제한된 접근 보너스 | 평균 훈련 점수 |
| R0S1 | 기존 보상 | 완료율 우선·평균 훈련 점수 차순위 |
| R1S1 | 기존 보상+제한된 접근 보너스 | 완료율 우선·평균 훈련 점수 차순위 |

R1은 목표별 최소 방문 거리의 새 감소에만 `감소거리/60`을 더한다. 이는 η=0.1의 `η×감소거리/6`이다. 이동만 보너스를 받으며 수집·벽 충돌·목표 전환 초기화에는 보너스가 없다. 각 목표는 최대6거리, 세 목표 합계 최대18단위=0.3이다. 왕복으로 같은 감소를 재보상하지 않는다. 이전 거리로 후퇴할 때 보너스를 회수하지 않는, 명시적으로 목표 함수를 바꾸는 조작이다. 정책 입력에는 보너스·최소 거리·미래 목표를 제공하지 않는다.

정책의 실제 행동·환경 보상은 모든 조건에서 기존 규칙이다. R1은 번식 점수 계산에만 개입한다. 검증 후보 선발은 공통 `(완료율, 기존 평균 보상)`이고 시험도 기존 환경으로 한다. R1 훈련 점수를 최종 능력 점수로 해석하지 않는다. R1 총점은1/300 정수 단위로 합산하며 R0의 기존 부동소수점 합산은 유지한다.

S1은 실수 가중합 대신 순서쌍을 사전순 비교한다. 모든 훈련 완료율이0인 집단에서는 S1과 S0 순위가 같다는 점을 명시한다. 실제 순위·상위4개·보상/완료율의 충돌 쌍이 얼마나 달라지는지 기록한다. 순위만 사용하는 기존 토너먼트·교차에 동률을 보존한 순위값을 전달하며, R0S0의 유전체·난수 궤적이 기존 구현과 같은지 검사한다.

## 2. 반복·비교·기준선

본 시드는401~420의20개, 확인은501~520의20개로 분리한다. 예비는911/912다. 시드 수20은 Q1-004의 큰 편차를 반영한 실행 전 결정이며 개체당 탐색량 증가는 아니다. 결과를 본 뒤 시드 수를 늘리지 않는다.

본 비교는 네 진화 조건×20=80실행과 공통 독립 무작위 개체 탐색20실행, 총100실행이다. 무작위 탐색에는 번식이 없고 후보 선발은 공통이므로 네 조건에 중복 실행하지 않는다. 공유 대조임을 표시하며 독립 표본80개로 세지 않는다. 검증용 작은 fixture에서 네 조건의 무작위 개체·검증 선발 궤적 일치를 검사한다.

훈련756·검증252·테스트504의 기존 분할과 목록을 재사용한다. 새 시드는 새 환경 일반화가 아니다. 훈련 묶음은 시드·회차로 파생하며 조건 간 공통이다. 평가 난수도 조건명과 분리한다. 최초 집단과 random의 탐색 난수는 기존 파생 규칙을 유지한다.

검증은0,9,19,…,99회차의 전20개체×252목록×3반복이다. 누적 best·첫 회차 initial·마지막 final을 보존하고 동점은 최초 후보 유지다. 모든 실행과 검증에서 선발한 blind를 잠근 뒤 시험504×3반복을 연다. 같은 실행의 동일 유전체 역할은 캐시 재사용하고 실제 호출을 별도 계수한다.

## 3. 주 대비·통계·확인

Q1-R01의 두 단독 대비 초안에 조합 대비를 추가해 세 대비를 한 검정군으로 고정한다. 조합만 효과가 있는 경우의 확인 규칙도 결과를 보기 전에 정하기 위한 변경이다.

1. R1S0−R0S0.
2. R0S1−R0S0.
3. R1S1−R0S0.

진화 주 후보의 시드 쌍20개 완료율 차이가 주 자료다. 평균·중앙값·표준편차·전체 분포와 양수 시드 수를 보고한다. 부트스트랩은 시드 단위10,000회, NumPy default_rng(72005)의 공통20×10,000 재표본으로 개별2.5/97.5백분위 구간을 계산한다. 동시 신뢰구간으로 부르지 않는다. 정확 단측 부호 검정에서0은 양수로 세지 않고 세 대비를 Holm(0.05) 보정한다. 이 검정의 대상은 양수 개선 확률이며 평균 자체가 아니다.

평균 차이의 경계 비교에는1e-12의 수치 오차만 허용한다. 진행 기준은 평균 차이≥10%포인트·양수≥15/20·Holm 통과의 결합이다. 통과한 조건 중 R1S0→R0S1→R1S1 순서로 한 조건만 확인한다. 최대 관측 효과로 사후 선택하지 않는다. 모두 실패하면 확인하지 않는다.

확인은 지정 조건+A0/R0S0의 진화40실행과 같은 새 시드의 공유 무작위 탐색20실행으로 총60실행이다. 새20쌍의 평균≥10%포인트·양수≥15/20·단측 부호 p≤0.05를 모두 만족해야 확인 통과다. 확인 실패 후 대상을 바꾸거나 본·확인을 합쳐 통과로 바꾸지 않는다.

상호작용 `R1S1−R1S0−R0S1+R0S0`, 진화−random/blind, 역할별 초기·마지막 성적과 탐색 경과는 보조·탐색적이다. 보조 비교 전체의 보정된 유의성을 주장하지 않는다. 시드별80% 완료율 달성 여부는 기술적 안정성 지표이며 추가 주 판정으로 바꾸지 않는다.

## 4. 반응과 회복의 측정

35쌍 초기 상태 프로브를 보조로 유지하며, 실제 시험 기록에서 첫 행동 정답률·첫 행동 오류 뒤 완수율·목표 전환 직후 정답률·실패 중 마지막6행동 반복률을 각각 분모와 함께 보고한다. 초기 반응과 과정 전체 회복을 하나의 능력 수치로 합치지 않는다. 반사 관찰은 이번 조작의 주 질문이 아니므로 실제 경로 재생 기반 진단을 사용한다. 방문 상태 수를 독립 탐색 반복으로 세지 않는다.

본 훈련4,800,000·검증16,632,000이다. 확인 훈련2,880,000·검증9,979,200이다. 기준선·프로브·기술 검사·기록 재생·중단 후 재계산은 별도 계수한다. 예비 성적을 보고 조건·계수·판정을 바꾸지 않는다. 예비는2회차 중단+3회차 재개와 비용만 확인한다. 비용 상한을 넘거나 기술 오류가 나면 미실행을 낮은 성능으로 처리하지 않고 원인을 보존한다.

기존 v0.1·v0.2 Python 소스와 결과는 수정하지 않는다. 새 패키지는 `studies/interaction/evosim_q1005_v01/`, 결과는 `studies/interaction/results_q1005_v01/`이다. 네트워크·유전 연산 등은 해시가 고정된 v0.2 의존성을 재사용하고 새 평가·보상·선발·프로토콜을 별도 구현한다. 소스 매니페스트는 새 코드·검사와 의존 소스 전부를 포함한다. 소스·자료·조건·환경이 바뀐 재개를 거부한다. 완료 원자료를 소급 수정하지 않는다.

필수 검사는 R0 동작 일치, R1 행동 불변·상한·왕복/목표 전환 예외·scalar/batch 일치, S0 순위 치환 동치·S1 순서·동률, 공유 random 동치, 모든 단계의 중단/재개·원자료 감사·후보 잠금·통계의 합성 사례다. 검사·훈련 전용 예비 후에만 실행 소스를 잠근다. 기술 오류는 보존하고 새 버전으로 처리한다.
