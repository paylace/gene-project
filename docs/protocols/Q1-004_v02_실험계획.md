## 1. 목표와 해석 범위

출력 자기순환을 금지한 상태에서 처음부터 진화시키면 기존 구조보다 과제 수행이 개선되는지 확인한다. 모든 기억 경로를 없앤 재진화도 비교하되, 출력 자기순환의 효과와 전체 구조 변경 효과를 구분한다. 기존 후보에서 평가 시 상태만 제거한 Q1-002와 다른 질문이다.

행동 고착·1목표 수집에 머무르는 선발은 원인 가설이다. 기존 감사와 테스트가 모든 버그의 부재를 증명하지 않는다. 점수 개선은 이 과제의 탐색 결과이며 일반적 지능·생애 학습·기억 능력의 우열로 확대하지 않는다. Q1의 생애 학습은 이번에도 꺼 둔다.

## 3. 바꾸는 조건과 고정하는 조건

| 조건 | 출력 자기순환 | 다른 그래프 순환 | 모듈 연산 | 질문 |
|---|---|---|---|---|
| A0 | 기존 허용 | 기존 허용 | 기존 6종 | 새 실행 체계의 동시 대조 |
| A1 | out_i에서 같은 out_i로 가는 간선만 금지 | 유지. 출력 간 교차 순환도 허용 | 기존 6종 | 해당 자기순환 경로를 금지한 탐색의 효과 |
| A2 | 금지 | 전부 금지 | linear/threshold/relu/tanh | 기억 없는 구조 전체의 탐색 가능성 |

각 조건의 방법은 evolution과 random 두 종류다. random은 매 회차 새 독립 개체를 만들며, 한 조건·시드의 첫 집단 20개는 두 방법에서 동일하다. A1에도 다른 순환으로 이루어진 간접 피드백이 남을 수 있으므로 ‘출력 피드백 전체 제거’라고 부르지 않는다.

환경은 기존 일곱 칸, 세 목표, 4입력, 좌/우/수집 3행동, 24스텝 상한을 유지한다. 올바른 수집 +1, 모든 행동 -0.01, 세 목표 완료 시 종료다. 보상·관측·종료·argmax 및 동률 처리·입력 정규화·가중치 범위·모듈 수 한도·엘리트/교차/변이/토너먼트 비율은 A0와 공통이다. 행동 보완·자동 수집·로짓 클리핑 변경·순환 부호 변경·생애 학습 도입은 이번 조건에 넣지 않는다.

### 초기화와 유전 연산의 구체적 규칙

동일 시드의 v0.1 초기 생성기를 기준으로 공통 원형 개체를 먼저 만든다. A0는 그대로, A1은 출력 자기순환만 삭제한다. A2는 모든 rec를 비우고 ema/latch 모듈을 tanh로 치환하며 bias·memory_decay 수치는 보존한다. 따라서 A2는 ‘제한된 4종 연산에서 균등 초기화’ 조건과 다르다. 이 선택과 초기 연산 빈도를 기록한다. 공통 부분의 가중치를 다시 뽑지 않는다.

변이 종류의 원래 제안 가중치 [0.42,0.12,0.06,0.18,0.22,0.10]을 유지한다. 합계 1.10으로 정규화한 확률로 추첨하며, 각 수치를 직접 확률로 해석하지 않는다. 금지 간선 생성 시도는 no-op으로 기록한다. A2의 add_rec는 모두 no-op이며 remove_edge는 원래의 rec/ff 선택을 유지하므로 rec를 선택했다면 no-op이다. ff로 강제 전환하지 않는다. 모듈 연산 변경은 원래 6종 제안을 유지하되 A2에서 ema/latch가 제안되면 기존 연산을 유지한다. 새 모듈 생성에서 금지 기억 연산이 제안되면 초기화와 같이 tanh로 치환한다. 다른 가능한 간선이나 연산이 나올 때까지 재추첨하지 않는다.

자기순환 이외의 허용 유전자·변이는 유지한다. 교차·역직렬화의 입력 부모/개체는 먼저 조건을 검증하며 위반 입력은 조용히 수리하지 않고 오류로 중단한다. 정상 부모의 자손도 검증한다. 최초 원형에서 조건별 초기 집단으로 변환하는 명시적 단계만 예외다. A2의 빈 간선 사전은 제거해 rec == {}를 강제한다. 무효 제안율·실제 유전자 변경률을 조건별로 기록한다. 이 설계는 제안 시도 예산을 맞추며 유효 변이 수까지 같게 만들지는 않는다.

## 4. 소스 보존과 실행 전 검사

기존 evosim_interaction 소스와 results_v01은 변경하지 않는다. 신규 패키지 위치는 studies/interaction/evosim_interaction_v02/, 출력은 studies/interaction/results_v02/로 정한다. 구현 시 이 문서와 일치하는 경로·명령을 추가하고 버전을 올린다. 아직 존재하지 않는 명령을 실행 가능한 것으로 표시하지 않는다.

실행 설정은 인스턴스별 불변 객체로 전달한다. 전역 설정 변경으로 다른 조건에 영향을 주지 않는다. protocol에는 조건, 방법, 시드, 분할, 코드/설정 해시, 난수 파생 규칙, 변이의 무효 처리, 선발 및 중단 규칙을 저장한다. checkpoint 식별자에도 조건·방법·시드·해시를 넣고 다른 조건으로 재개를 거부한다.

필수 검사:

- A0 초기 생성·순차/묶음 평가·주요 유전 연산을 v0.1과 동일 입력·난수 상태에서 대조한다. 비슷한 점수가 아니라 개체 직렬화·행동·보상·선발 결정 일치를 검사한다. 기록 추가가 난수 소비를 바꾸지 않아야 한다.
- A1 출력 자기순환 없음, A2 모든 rec 없음 및 기억 연산 없음이 초기화·각 연산·교차·저장·재개 뒤 유지되는지 검사한다. 강제로 금지 제안이 발생한 사례도 포함한다.
- 모든 저장 개체를 감사하여 불변조건·상위 모듈 ID·부모 추적·조건별 설정을 검증한다. 검사 오류는 성능 실패로 집계하지 않는다.
- 평가 전후 유전체 해시 불변, 에피소드 상태 초기화, 묶음/개별 행동·보상 일치를 검사한다. 전체 1,512조합에서 규칙 정책의 해결 여부와 최단 거리 계산을 확인한다.
- 기존 동결 소스 30개의 해시 검사를 유지하고 기존 테스트도 통과해야 한다.

A0 정합성 실패, 조건 누출, 재개 불일치가 있으면 실행을 중단한다. 수정 전 실패 기록은 보존하고 새 소스/프로토콜 버전으로 재시작한다. 본 실험 점수를 본 뒤 조용히 조건을 고치지 않는다.

## 5. 분할·선발·난수·예산

기존 split_seed=71001과 분할 해시 965983b00ce3e8465d70cd82e637773e6599065f68db8beec8b248cd328242f6을 그대로 사용한다. 훈련 756, 검증 252, 테스트 504개 목록이다. 좌우 반전 목표 목록은 같은 분할에 둔다. 이미 v0.1 결과를 본 벤치마크에 대한 계획된 후속 비교임을 모든 결과에 표시한다.

매 세대 훈련 24개 목록은 derive_seed("training_batch", seed, generation)로 공통 생성한다. 평가의 purpose·run_seed·episode_id·repeat 조합도 조건 간 공통이며 조건명으로 평가 난수를 갈라 놓지 않는다. 탐색/초기화와 평가/훈련 묶음 난수는 분리하고 각 파생 규칙을 manifest에 저장한다. 방법 간 탐색 난수는 기존대로 분리한다.

번식 선발은 훈련 평균 보상, 후보 선발은 검증 성공률·평균 보상 사전순이다. 검증은 0,9,19,…,99회차의 전체 20개체에 각 3반복 적용한다. 동점이면 먼저 관측한 후보를 유지한다. 주 후보 best, 0세대 후보 initial, 마지막 세대 후보 final의 정의를 고정한다. 모든 조건·방법·시드의 후보와 blind 후보를 잠근 뒤 테스트를 열며 테스트 결과로 후보나 조건을 재선발하지 않는다.

| 단계 | 범위 | 훈련·검증 에피소드 평가 수 |
|---|---|---:|
| 예비 | 시드 901,902 × 3조건 × 2방법 × 20개체 × 5회차, 훈련만 | 28,800 |
| 본 비교 | 시드 201~210 × 3조건 × 2방법 × 20개체 × 100회차 | 훈련 2,880,000 + 검증 9,979,200 = 12,859,200 |
| 예약 확인 | 시드 301~310 × 선발 구조 1개와 A0 × 2방법 × 동일 예산 | 최대 8,572,800 |

본 비교는 총 60개 탐색 실행이며, 후보 평가 슬롯은 훈련 120,000개·검증 13,200개다. 1실행의 검증 후보 슬롯은 220개다. best/initial/final 테스트는 본 비교에서 60 × 3 × 504 × 3 = 272,160 에피소드 평가다. 그중 주 후보만 90,720개다. 예약 확인의 세 역할 테스트는 최대 181,440개다. 같은 유전체가 여러 역할이면 평가 결과를 재사용하고 실제 실행 횟수와 논리적 슬롯 수를 함께 기록한다. 프로브·기준선·정합성 검사는 별도 계수하고 예산을 숨기지 않는다.

예비에서는 테스트를 열지 않으며 성능에 따라 조건·예산·임계값을 고르지 않는다. 실행 시간·디스크·오류·재개 비용만 확인한다. 예비의 실제 처리 속도와 로그 크기로 총 비용을 추정해 계획 버전에 기록한다. 현재 소요 시간은 미측정이며 임의 ETA를 쓰지 않는다. 낮은 점수를 이유로 시드·회차를 추가하지 않는다.

## 6. 지표·분석·사전 판단

주 지표 S는 동결 best 후보의 세 목표 완료율이다. 반복 3개·테스트 504개를 먼저 시드별로 평균한다. 통계 표본 단위는 탐색 시드 10개이며 에피소드·프로브·스텝을 독립 실행으로 세지 않는다.

### 구조 변경 효과 — 주 검정군

두 대비 d1=S(A1,evolution)−S(A0,evolution), d2=S(A2,evolution)−S(A0,evolution)를 미리 지정한다. 각 대비의 평균·표준편차·양수 시드 수와 짝 부트스트랩 10,000회 95% 백분위 구간을 보고한다. 동일 bootstrap 난수 72004와 같은 시드 재표집 인덱스를 두 대비에 사용한다. 이 95% 구간은 개별 대비의 설명용 구간이며 동시 신뢰구간이라고 부르지 않는다.

주장의 다중 비교는 두 대비의 단측 정확 이항 부호 검정으로 제어한다. K는 차이가 엄밀히 양수인 시드 수이며 0 차이는 비양수로 센다. 귀무가설은 시드 분포에서 개선 확률이 1/2 이하라는 것이다. p=P(Binomial(10,0.5)≥K)를 계산하고 두 p값에 Holm 절차(작은 값 0.025, 나머지 0.05)를 적용한다. 이 검정은 평균 차이의 검정과 다르므로 ‘평균 효과의 유의성’으로 바꿔 서술하지 않는다. 8/10의 단측 p는 0.0546875, 9/10은 0.0107421875이므로 8/10 조건만으로는 검정이 통과하지 않는다. 이산 검정·10시드의 낮은 검정력도 명시한다.

‘일관되고 실질적인 구조 개선’의 진행 기준은 평균 차이 ≥10%p, 양수 시드 ≥8/10, Holm 통과를 모두 만족하는 것이다. 차이를 확인하지 못하면 해당 예산에서 근거 부족으로 결론 내리며 동등성·효과 없음의 증명으로 쓰지 않는다. A1이 통과하면 A1을 예약 확인 대상으로 지정하고, A1이 실패하고 A2만 통과하면 A2를 지정한다. 둘 다 실패하면 예약 확인을 자동으로 추가 실행하지 않는다. 최대 차이가 큰 조건을 사후 선택하지 않는다.

### 별도로 구분할 주장 — 보조 분석

- 환경 관측 이용 능력: 각 조건의 evolution−blind 평균 차이 ≥10%p, 시드별 짝 부트스트랩 95% 하한 >0, 양수 ≥8/10 및 35쌍 프로브의 양방향 정답률 ≥80%를 만족하는 시드 ≥8/10을 능력 기준으로 표시한다.
- 진화 탐색 이득: 각 조건의 evolution−random 평균 차이 ≥10%p, 같은 95% 하한 >0, 양수 ≥8/10을 기준으로 표시한다.
- 이 여섯 보조 대비의 구간과 기준 충족 여부는 탐색적 결과다. 주 검정군의 Holm 보정으로 이 주장들까지 보정됐다고 쓰거나 여러 기준 중 통과한 것만 연구 성공으로 선언하지 않는다. 구조 효과·관측 이용·진화 이득을 각각 판정한다.

blind는 기존 고정 행동 순서 후보군을 검증셋에서만 선발하고 인덱스를 잠근다. 같은 과제의 구조 조건에 공통으로 사용한다. 새 규칙·무작위 행동 기준선도 같은 환경에서 검사한다. 35쌍 프로브는 기존 정의·동률 난수 3반복·상태 초기화를 유지하고 정확한 관측 목록을 manifest에 담는다.

예약 확인에서는 선택된 한 구조와 A0만 새 시드 301~310에서 처음부터 탐색한다. 단일 주 대비에 평균 ≥10%p, 양수 ≥8/10, 단측 정확 부호 검정 p≤0.05를 적용한다. 구조 선택 후 같은 시드에서 다시 조정하지 않는다. 실패하면 본 비교의 개선이 새 탐색 시드에서 확인되지 않았다고 보고하며 반복 확인을 덧붙이지 않는다. 환경 일반화·보상 변경은 후속 별도 계획이다.

## 7. 행동 진단과 기록

본 비교의 주 후보에 대해서만 추가 진단을 수행한다. initial/final은 성능 추적용이다. 진단 로그 수집은 정책 상태·선택·난수 소비를 바꾸지 않는 관찰자로 구현한다.

- 마지막 6행동 동일 실패 수를 전체 에피소드 수와 전체 실패 수 두 분모로 각각 보고한다. 짧아 6행동이 안 되는 에피소드의 집계 규칙은 v0.1 분석과 일치시킨다.
- 실패 수집 횟수/에피소드, 벽 충돌, 목표 변경 뒤 첫 행동의 올바른 이동 비율을 분자·분모와 함께 저장한다. 목표 변경이 없는 시드는 0으로 대체하지 않고 해당 없음으로 표시한다.
- 매 행동의 3개 로짓·최댓값과 차순위 격차·정답 행동과 선택 행동의 차이를 기록한다. 절대 크기, 공통 모드 변화와 행동 간 격차를 구분한다.
- 동일한 전체 이전 네트워크 상태를 복제한 뒤 현재 목표 좌표 입력만 g에서 g'=2x−g로 바꿔 행동을 비교하는 반사 관측 검사를 보조 진단으로 둔다. 정수 위치 x와 목표 g에 대해 g≠x이고 g'가 0~6인 방문 상태만 대상으로 한다. 위치·남은 목표 수·예산·모듈/순환 이전 상태는 유지한다. 동률이면 복제한 같은 난수 상태로 두 행동을 계산한다. 두 입력에서 올바른 반대 이동을 모두 선택한 비율과 단순 행동 전환 비율을 분리하고 적격 상태 수를 보고한다. 도달하지 않은 반사 관측일 수 있으므로 개입 진단이라고 명시한다. 원래 롤아웃에 이 상태를 되돌려 넣지 않는다.
- 모든 조건의 실패 시드·불변조건 감사·무효 변이·코드/설정/분할/초기 집단/후보 해시·실행 명령·환경 버전·중단과 재개·벽시계 시간을 보존한다. 비유한 활성이 나오면 낮은 점수로 조용히 바꾸지 않고 기술 오류로 중단한다.
