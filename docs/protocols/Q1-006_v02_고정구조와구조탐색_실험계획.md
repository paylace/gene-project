# Q1-006 — 고정 구조와 구조 탐색의 비교 계획

버전1.1 / 실행 v0.2, 작성2026-10-17 한국 시간. 새 F0/F1 탐색 결과를 보기 전 작성했다. 상태: 구현·검증 준비. 수치 명세는 [q1_006_v02_plan.json](q1_006_v02_plan.json)이며 예비 뒤 동일 소스·계획 해시와 실행 프로토콜을 잠근다. 사용자에게 계속 실험하도록 승인받았다. 완료한 이전 소스·원자료는 변경하지 않는다.

## 실행 전 기술 개정

v0.1 예비는 계획8작업 중6작업만 생성했고 완료 판정이 false여서 본 진행 자격을 얻지 못했다. 본 실험은 시작하지 않았다. 원본35소스·게이트·계획·14,400호출·비용 표본3,120호출을 보존했다. v0.2는 예비에만 양쪽 무작위 대조를 생성하고 미완료 예비의 비정상 종료를 추가한다.8작업 구성 검사를 추가하며 과학적 조건·40쌍·주 대비·판정은 그대로다. 새 패키지·수치 명세·게이트·출력 폴더로 분리한다.

## 1. 질문과 가설

같은 해결 가능한 초기 템플릿에서, 가중치·편향만 바꾸는 F0가 구조도 변경하는 F1보다 주어진 탐색 예산에서 더 높은 완료율을 얻는가? [Q1-009](../reports/Q1-009_초기반응과고착_요인분리.md)는 초기 고착 진단이며 이 질문의 답이 아니다. [수작업 템플릿 검사](../management/Q1-006_템플릿_준비검사.md)는 해결책 존재만 확인했다. 정답 가중치를 초기 집단에 넣지 않는다.

F0−F1이 양수이고 사전 진행 기준을 통과하면 이 예산의 구조 자유도 부담이라는 가설을 새 시드에서 확인한다. F1이 더 좋으면 반대 방향도 그대로 보고하되 사후에 확인 대상을 바꾸지 않는다. 둘 다 낮으면 규모 부족으로 단정하지 않고 변이·적합도 신호·다양성을 점검한다.

## 2. 조건과 공통 요소

| 조건 | 가중치·편향 | 모듈·순방향 연결 | 연산·순환 |
|---|---|---|---|
| F0 | 변경 허용 | 초기 구조 고정 | tanh만, 순환 금지 |
| F1 | 변경 허용 | 모듈4~9개, 추가·제거 허용 | tanh만, 순환 금지 |

초기 네 모듈에 입력→모듈16개·모듈→출력12개를 전부 둔다. 모듈 간 연결은 처음에 없다. 편향은 U(−0.4,0.4), 입력 연결은 U(−1.5,1.5), 출력 연결은 U(−1,1)에서 독립 생성한다. memory_decay=0.5는 tanh에서 사용되지 않는 고정 직렬화 값이다. F0/F1과 같은 시드의 무작위 탐색은 동일한 초기 집단으로 출발한다. 이후 구조별 난수 소비가 달라질 수 있으며 매 세대 모든 난수 추첨이 일치한다고 주장하지 않는다.

환경은 기존7칸·순차3목표·24행동이다. 위치/목표0~1·남은 목표 비율·남은 행동 비율의 네 관측, 왼쪽/오른쪽/수집 세 행동을 유지한다. 좌표 중심화는 하지 않는다. 보상은 수집+1·매 행동−0.01, 번식 기준은 훈련 평균 보상 R0/S0다. 생애 학습은 끈다. 단순한 순방향 구조를 다루므로 이번 결과가 기억 진화 전체를 판정하지 않는다.

네트워크 직렬화에는 호환성을 위해 기존 Settings("A2")를 쓰고 새 유전체·조건 검증에서 tanh·순환 없음·가중치 범위와 F0 연결을 추가 강제한다. 기존 A2의 다양한 연산을 실제로 허용하는 것이 아니다. 전체 A0와 F0의 과거 성적 차이를 구조 자유도 하나의 인과 효과로 해석하지 않는다.

## 3. 변이·교차와 예산의 뜻

집단20·100회차, 상위20% 엘리트·크기3 토너먼트, 교차 확률0.65·자손 변이 확률0.5를 쓴다. 우성 부모는 훈련 순위·동률 슬롯 순서로 결정한다. 공통 유전자는 확률0.5로 둘째 부모 값을 사용하고 비공통 순방향 연결은 기존0.3 확률과 DAG 검사를 사용한다. 모듈 집합은 우성 부모를 따른다.

변이 종류의 원 가중치(합1.10)는 weight .42 / add_module .12 / remove_module .06 / add_ff .18 / add_rec .22 / remove_edge .10이다. 이를 합으로 정규화해 하나를 뽑는다. F0의 구조 제안과 양쪽 add_rec는 무효 시도로 남기며 가중치 변이로 재분배하지 않는다. F0의 금지 제안은 종류 선택 뒤 즉시 종료하므로 F1의 세부 제안 RNG 소비를 흉내내지 않는다.

weight 제안은 최대2개 모듈을 골라 각각 확률0.35·표준편차0.25로 편향을 변경하고, 모든 존재하는 순방향 연결을 각각 확률0.35·표준편차0.35로 변경한다. 가중치±3·편향±2로 제한한다. 연산·decay는 변경하지 않는다. F1 추가 모듈은 tanh·무작위 편향·입력 또는 기존 모듈 하나에서 들어오는 연결·무작위 출력으로 나가는 연결로 만들며 새 가중치는 U(−1.2,1.2)다. 최소4·최대9개를 지킨다. 제거·추가 간선의 중복·순환·제거 대상 없음도 기록한다. remove_edge에서 원래 확률0.4로 순환 매핑을 고르면 대상 없음으로 끝난다.

모듈 ID는 각 탐색 실행의 단조 증가 카운터다. 실제 파라미터 변경·구조 변경·금지·기타 무효·교차를 로그에서 재구성한다. 비교는 **같은 제안 방식과 평가 예산에서의 탐색 방법 전체**다. 구조가 커지면 weight 제안 하나에 바뀌는 가중치 수도 늘 수 있다. 유효 변경 수·연산량까지 맞춘 구조의 순수 효과라고 부르지 않는다. 실제 변경 수를 맞추는 별도 보조 조건은 이번에 추가하지 않는다.

## 4. 표본·평가·후보 잠금

본 시드1001~1040의40쌍, 조건부 확인1101~1140의40쌍을 사전 예약한다. 기존 성공 시드를 골라 넣지 않는다. 각 시드에서 F0진화·F1진화·공통 무작위 탐색의3작업을 실행한다. 무작위 탐색은 매 회차 같은 초기 템플릿 분포에서20개체를 독립 생성한다. F0/F1이 이 분포와 검증 기준을 공유하므로 하나의 대조를 두 진화 조건과 비교한다. 이 보조 대비는 기술 통계이며 추가 진행 경로가 아니다.

기존 고정 분할의 훈련756·검증252·테스트504목록을 재사용한다. 환경을 이미 보았으며 새 시드는 새 환경 일반화가 아니다. 매 회차 훈련24목록을 시드·회차로 추출한다. 검증은0,9,19,…,99회차의 전20개체에3난수 반복으로 한다. 모든 조건에서 검증 완료율·원래 평균 보상·최적 행동 수 대비 추가 행동 순의 공통 기준으로 best를 고르고 동률이면 먼저 본 후보를 유지한다.

검증 best·0회차 best·마지막 회차 best와 관측 없는 행동 순서 기준선의 후보를 전부 잠근 뒤 테스트를 연다. 테스트504×3회 반복. 같은 작업에서 역할의 유전체가 같으면 같은 결과 캐시를 공유하고 실제 호출은 한 번만 센다. 테스트로 후보·조건·문턱을 재선발하지 않는다. 동결·역할·분할·소스·프로토콜·완료 파일 해시와 재개 RNG를 검사한다.

## 5. 주 분석과 진행·중단

독립 표본 단위는40개 탐색 시드다. 주 결과는 검증으로 선발한 best의 테스트 완료율, 주 대비는 F0−F1 하나다. 평균·중앙 짝 차이·표준편차·양수/음수/동률·개별 원값과 짝 bootstrap10,000회(난수72006)의 개별95% 기술 구간을 보고한다.

본 비교의 **평균 차이≥10%포인트이고 한쪽 정확 부호 검정 p≤0.05**이면 같은 두 조건의 새40쌍 확인으로 진행한다. 부호 검정은 절댓값≤1e−12의 동률을 제외한 양수/음수 시드에서 P(F0>F1 | 차이≠0)>0.5를 검정한다. 평균 차이의 유의성 검정과 구분한다. 평균 문턱과 이 검정의 결합이 평균 효과의 신뢰하한을 보장하지 않는다. 하나의 사전 대비이므로 이번 단계 안의 다중 비교 보정은 없다. 여러 후속 연구 전체에서 선택한 결론이라는 탐색 한계는 남는다.

완료율80% 이상을 얻은 시드 수/40과 그 차이, 최초 검증 best가80%에 도달한 회차·누적 평가 비용을 보조로 기록한다. 최고1개체가 성공해도 안정적 발견이라 부르지 않는다. 발견 비율·보조 대비·초기 반응률로 주 진행 실패를 뒤집지 않는다.

성공/실패가 양극화되고 동률이 많은 모의 분포에서 사전 판정의 통과 확률을 계산해 검출력 한계를 남긴다. 이는 실제 새 실험 자료가 아니며40쌍의 충분한 검출력을 보증하지 않는다. 예비 성적을 이용해 문턱이나 표본 수를 바꾸지 않는다.

확인에서도 같은 기준을 통과해야 재현 근거로 본다. 실패하면 반대 조건 확인·시드 추가·예산 연장을 하지 않는다. 오류·데이터 누출·원자료 불일치는 해당 단계 판정을 중단하고 보존·진단한다. 조건이나 코드 변경이 필요하면 새 버전·출력 폴더로 분리한다. 동등성·일반 지능 불가능성은 이번 판정 대상이 아니다.

## 6. 예비·전체 작업량

훈련 전용 예비는1901·1902 시드에서 두 조건×진화/무작위의8작업·5회차다.2회차 중단 뒤 재개하고 전체 유전체·행동·선발·RNG를 감사한다. 검증·테스트는 열지 않는다. 성능 기반 조건 선택 없이 시간·원자료 크기를 산출한 뒤 본 프로토콜을 잠근다.

| 단계 | 작업 수 | 탐색 에피소드 | 역할 테스트 논리 슬롯 | 초기 단일 상태 계산 / 감사 |
|---|---:|---:|---:|---:|
| 예비 | 8 | 19,200 | 0 | 0 / 0 |
| 본 | 120 | 25,718,400 | 544,320 | 52,920 / 52,920 |
| 조건부 확인 최대 | 120 | 25,718,400 | 544,320 | 52,920 / 52,920 |

한 본 작업은20×(100×24+11×252×3)=214,320호출이다. 기준선 선발140×252=35,280호출, 테스트는blind504+uniform10,080+coordinate504=11,088호출이며 본에서 별도 수행한다. 확인은 고정 기준선 원자료를 재사용하고 새 호출로 세지 않는다. 단위 검사·수작업 정합성·추가 비용 표본은 별도로 계수한다. 예비만으로 장시간 본 비용을 정확히 보장하지 않는다.

초기 반응성은 Q1-009의 수정 방식인441상태·반대 정답 좌우315쌍·수집63상태에서 실제 softmax 동률 집합으로 계산한다. 최종 best만 검사하고 감사에서 출력을 재계산한다. 각 초기 상태 호출은 에피소드 호출과 합치지 않는다. 전체 탐색의 행동 기록은 환경·보상·종료로 재생하되 전체 신경망 출력을 모두 재계산한 감사와 구분한다. scalar/batch는 기술 검사에서 대조한다. UUID 원장으로 실제 완료 호출·중단 미확정 상한·캐시 재사용을 기록한다.
