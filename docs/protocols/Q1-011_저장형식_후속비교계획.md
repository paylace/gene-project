# Q1-011 후속 기술 계획 — 실제 관측 열의 직접 저장

작성일: 2026-10-17. 원래 [최적화 계획](Q1-011_실험기반_최적화계획.md)의 첫 벤치마크를 완료한 뒤 작성한 사후 기술 보완이다. 원래 결과·소스·비용은 보존한다.

첫 기반은 같은 정책 결과를2.2~7.4배 빠르게 평가했으나, 환경 재생과 예외 계산을 포함한 저장이 기존1.60초 대비12.42초, 복원이1.19초 대비7.24초였다. 저장 단계를 기본값으로 채택하지 않고 새 `evosim_runtime_v02/`에 실제 관측 열을 직접 저장하는 codec을 추가한다. 평가 커널은 v0.1을 재사용하며 변경하지 않는다.

보상·진행·결과를 다시 계산하지 않고 관측된 정수/불리언 배열을 작은 정수형과 base64로 저장한다. 범위를 넘거나 타입이 다르면 그 열을 원래 JSON 값으로 저장한다. 에피소드/반복 순서·유전체·행동열은 공유하고 모르는 필드·필드 누락도 보존한다. 환경 코드가 바뀌어도 이미 관측한 보상을 재생 없이 복원할 수 있어야 한다. schema·전체 원본/내용 해시는 유지한다. 입력 자료의 의미 검증은 별도 감사기의 책임이다.

기존 Q1-007의122파일 전체에 기존gzip3·새 열 저장·새 열 저장gzip9를 각각3회 측정한다. 쓰기/fsync·읽기/원본 바이트 비교·크기·메모리를 첫 측정과 같은 범위로 기록한다. 새 정책 호출0이다. 고의적인 오류값·새 필드·누락·손상·타입 차이·범위 경계를 기술 검사한다. 모든 비교 사본과 실패를 새 `optimization_q1011_v02/`에 보존한다.

Q1-007 본·확인과 추가 정책 평가는 이 보완에 포함하지 않는다. 첫 버전과 신규 버전의 장단점을 종합하여 기본 저장 경로를 제안하되 임의의 최소 크기를 보장하지 않는다.
