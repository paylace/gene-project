## Q1의 주 결과

후속 방향: [Q1-R01 계획서](protocols/Q1_구조_보상_탐색_규모_후속연구계획.md)에 구조 → 보상·번식 → 고정 구조 탐색 → 조건부 규모 비교를 기록했다. Q1-005 이후는 미실행 초안이며 새 성능 결과는 없다. 현재 실제 구현 작업의 다음 단계는 Q1-004 W3/W4로 유지한다.

| 조건 | 세 목표 완료율 |
|---|---:|
| 진화 | 0.1786% |
| 같은 예산의 무작위 개체 탐색 | 0.1521% |
| 무작위 행동 | 1.0516% |
| 선발한 고정 행동 순서 | 4.3651% |
| 좌표 비교 규칙 | 100% |

이 표는 Q1 조건의 요약이다. 진화의 우월성이나 일반적인 지능의 유무를 확정하지 않는다. 수치의 세부 근거와 불확실성은 실험 보고서에서 확인한다.
